# ゼロ次ホールドによる離散化

連続TransferFunctionの変換欄で「離散化方式」を **ゼロ次ホールド（ZOH）** にし、周期を入力して係数を確認・適用します。既存のTustinと同じモデル編集・Undo・保存／復元を使います。初期状態0のみです。ZOHではプリワープ欄を無効にし、その値は変換へ渡しません。方式・周期・モデル変更後は再確認が必要です。

## 数学的な対象

各区間 `[kTs,(k+1)Ts)` で入力を一定のu[k]に保持した連続線形系を扱います。元の連続companion行列をA・B・C・Dとして、以下のサンプル時刻の実現を作ります。

```text
Ad = exp(A Ts)
Bd = integral(0..Ts) exp(A τ) B dτ
x[k+1] = Ad x[k] + Bd u[k]
y[k]   = C x[k] + D u[k]
```

Aの逆行列は使わず、`exp([[A,B],[0,0]] Ts)` の上側からAd・Bdを取り出します。積分器・原点の重根も対象。0〜8次、有限な実係数のproperな伝達関数です。ベクトルの各成分は独立したコピーとして実行します。

無限級数は数値計算です。行列の無限大ノルムを0.5以下へ縮小してTaylorを最大32項、最大24回の平方で戻します。項のノルムが `2e−17×max(1,結果ノルム)` 以下なら終了。行列・係数の非有限値、スケール／積の数値範囲外、平方回数超過、未収束は拒否します。

分母はAdの特性多項式、分子はC・Bdと随伴行列の係数から再構成し、zの降べき順で既存のDiscrete TransferFunctionへ戻します。元の次数を残し、極零相殺・最小実現は行いません。元の直接項Dも保持するため、厳密にproperな系に新しい直接項を作りません。

`A Bd=(Ad−I)B` の相対残差≤1e−10、Cayley–Hamilton残差≤1e−10、離散companionと元の離散行列の最初 `2n+4` 点のインパルス再構成差≤1e−9を確認します。比較差は1を含む尺度で正規化します。これらは必要な数値チェックで、任意の期間・周波数の誤差保証、厳密な安定性証明ではありません。特に高次・近接極・極端な尺度では未解決となる場合があります。

## Tustinとの違い

| 方式 | 主に合わせるもの | 初回の出力（初期状態0） |
|---|---|---|
| ZOH | 区間ごとに保持した入力に対するサンプル時刻の応答 | 元の直接項D×入力 |
| Tustin | 双一次写像による周波数応答、任意のプリワープ周波数 | 変換で生じた直接項×入力 |

`1/(s+1)` は `r=exp(−Ts)` として、ZOHで分子 `[0,1−r]`、分母 `[1,−r]` です。`1/s` は `[0,Ts]/[1,−1]`、`1/s²` は `[0,Ts²/2,Ts²/2]/[1,−2,1]`。2次ローパス `1/(s+1)²` は分母 `[1,−2r,r²]`、分子 `[0,1−(1+Ts)r,r²+(Ts−1)r]` です。初回は0で、次の出力は連続系のTsでのStep応答と一致します。

ZOHでも、表示する離散ブロックの出力はサンプル間で保持します。サンプル間の連続プラントの波形を再構成しません。元のSineや時計の間で変わるStepが連続系へ直接入っていた場合、それをサンプルした入力へ変えることでモデルの意味が変わります。連続入力の全時刻応答と同じとは扱いません。また、開ループを変換してから作ったサンプル帰還と、連続閉ループをそのまま離散化した応答は一般に異なります。

## GUIと保存

適用済みの分子・分母だけを変換します。確認中は元のモデル・結果・履歴を保持し、方式を含む入力条件やモデルが変われば係数確認を無効化。適用すると同じID・表示名・位置・幅・接続の離散ブロックに置き換え、1回のUndoで戻せます。記録時計・計算方式・解析領域は変えず、実行・解析・結果ファイル照合中は変換を拒否します。

非ゼロ初期状態の写像は未対応で、状態を黙ってリセットせず拒否します。周期は記録刻みの整数倍。既存の直接伝達循環は診断して拒否し、ZOHで直接項のない自己帰還は実行できます。階層の完全IDとベクトルの独立したゼロ状態を維持します。

変換係数・周期・初期状態は通常のモデル文書と実行結果ファイルへ保存できます。方式や元の連続係数の履歴をモデル文書へ追加する機能ではありません。元のモデルも必要なら変換前に別に保存してください。

## 検証とサンプル

[zoh.json](../samples/discrete/zoh.json) または「保持入力：ZOH離散化」を使います。2秒で入力を1から0へ下げる連続ローパスを、Ts=0.2sのZOHで変換します。

`cargo run --locked -p blocksim-core --example zoh` は一次／二次ローパス、二重積分器、振動子の8秒・801記録点を、独立した `Step(t)−Step(t−2)` とサンプル間の保持も含めて照合します。最大差は5.33e−15未満。201複素点を独立した離散伝達式と照合し、差/(1+|G|)は3.67e−11未満でした。[数値JSON](zoh-validation.json) にAd・Bd・C・D、係数、残差、初回6サンプルを保存しています。

Rustでは行列の独立式、静的Gain・積分器・振動子・4／8次の重根、1e300倍の係数、元の直接項、相殺した不安定な内部極を確認。保持したSineを使う連続RK45のサンプル時刻と離散出力も照合しています。実GUIでは方式切替・無効なプリワープ・係数確認／Undo・保存／再読込、エラー時の結果保持、閉ループ、離散Bode／内部安定性、実行中の拒否と320pxを確認しました。有限窓・選んだモデルでの検証です。

非ゼロ初期状態、モデル全体の一括変換、matched pole-zero、変換条件の履歴保存、最小実現、異なる周期／連続離散混在の周波数解析、9状態以上・MIMOは未実装です。
