# ブロック図モデル

「ブロック図エディタ」タブで任意の接続を持つ小規模な制御モデルを作れます。既存の PID Lab は独立した画面として維持します。

## 編集と実行

1. ブロック種類を選び「ブロックを追加」。ドラッグまたは位置 X / Y で配置します。
2. ブロックを選ぶと右側の設定欄にパラメータを表示します。配列は JSON、制限なしは空欄です。
3. ブロック右の出力ポート→左の入力ポートをクリックして接続します。番号と幅は各ポートのツールチップで確認できます。Escape／「配線をキャンセル」で中止できます。右側の接続フォームも使えます。ポート番号は0から。
4. 記録したい信号を Scope に接続し、「モデルを実行」。入力不足、幅の不一致、代数ループ、周期の不整合を検証してから WASM を実行します。
5. Scope の各成分を表示／非表示にし、カーソルで各記録点の値を確認できます。CSV は全系列・全記録点を出力します。

計算は Web Worker 内で行います。「実行を中止」やモデル変更でワーカーを終了し、古い計算結果の反映を防ぎます。モデルを変更するとグラフを無効化して再実行を促します。表示は最大16系列、数値計算と CSV はこの表示制限に影響されません。

Undo / Redo はモデル全体を最大50操作保持します。Ctrl/Cmd+Z、Shift+Ctrl/Cmd+Z、Ctrl/Cmd+Y は入力欄以外で使用できます。ブロックを削除すると関連接続も削除します。接続一覧の ×、または線を選択して「選択した接続を削除」／Delete で個別の線を削除できます。線の選択とポート操作は Enter／Space にも対応します。モデル変更で配線中の状態を解除します。失敗した接続は既存入力を上書きせず、履歴・計算結果を保持します。通常の幅、Mux の入力幅合計、Selector のインデックスを接続時に確認し、代数ループは実行時に検証します。座標は0〜10000で、キャンバスはブロックの配置に合わせて広がります。

## 実行結果の比較

実行が完了したら、Scope の結果の「基準として保持」で実行時のモデル設定と結果を1件保持できます。設定変更、Undo／Redo、モデルの置き換え・保存・復元、PID Lab へのタブ切り替えでも基準は残ります。現行モデルの変更で現行の結果は無効化されるため、再実行して比較してください。計算中や結果がない場合は基準を更新できません。失敗・中止した計算は基準を置き換えません。基準操作自体はモデル・位置・変更履歴・未保存判定を変えません。

「基準を重ねる」で実線の現行結果に同じ色の破線の基準結果を重ねます。対応する Scope は、階層パスを含む ID と信号幅が同じものです。名前が同じだけの別 ID や、幅が変わった Scope は対応させず理由を表示します。表示名の変更や Scope の記録順序の変更は比較できます。表示系列のチェックは対応する基準線にも適用され、現行は最大16系列、その基準線は最大16本です。刻み幅・終了時刻が違っても、それぞれの記録時刻と両者の終了時刻を含む横軸で波形を表示します。

記録時刻の配列が完全一致する場合、対応する各成分の `Δ = 現行 − 基準` を比較します。補間や近い時刻への丸めは行いません。カーソルには基準値とその時刻の差を表示し、一覧には最大絶対差・記録点の RMSE・終点の符号付き差・台形則による `∫|Δ|dt` を表示します。RMSE は時間重み付きではありません。これらは基準との差であり、基準自体が正解だと保証する評価指標ではありません。

比較一覧は表示系列の選択によらず全対応成分を含み、50件ずつページを送れます。「差分 CSV」は全対応成分・全記録点の差を出力します。通常の「CSV を書き出す」は現行結果のままです。記録時刻が異なる場合は数値比較を行わず、差分 CSV を無効にします。差の計算が有限値の範囲を超える場合も明示し、CSV に Infinity や欠落した数値を書き出しません。RMSE は値を正規化して計算し、単に二乗が範囲を超える場合でも有限の結果を求めます。

「基準を置き換える」は最新の成功した実行結果で更新し、「基準を解除」で解放します。「基準のモデル JSON」はその結果を計算したモデルの設定を書き出します。基準はブラウザタブのメモリー内に1件だけ保持し、ページ再読み込みで消えます。後述の実行結果ファイルに保存すれば、後から基準として読み込めます。モデル JSON と localStorage の保存形式は従来のままです。

## 実行結果ファイル

Scope の結果の「実行結果ファイル」を開き、「現行の結果を保存」または「基準の結果を保存」で、成功した実行時のモデル設定・全記録時刻・全 Scope の全成分・ソルバ情報を JSON ファイルに保存します。表示した系列の選択やカーソル位置によらず全記録点を含みます。現行結果がモデル変更で無効な場合や、実行・読み込み中は現行結果の保存を無効にします。ファイルはブラウザのダウンロード先に保存し、自動で localStorage には保存しません。

「基準の結果を読み込む」でファイルを選ぶと、保存したモデルを別の Web Worker で WASM 再計算し、時刻・Scope ID・名前・順序・幅・全数値・ソルバ情報・保存された統計が一致する場合だけ基準へ反映します。現在のモデル・結果・位置・履歴・未保存判定は保持します。再読み込み後や作成途中の現行モデルにも基準を読み込めます。読み込みはモデルの置き換えではなく、比較の基準の復元です。

読み込み中は通常の実行と基準の更新を待機させます。「読み込みを中止」でファイルの読み込み・確認を中止し、確認用ワーカーを終了します。中止した読み込みや古いワーカーの返答は反映しません。形式不正・不一致・再計算の失敗・中止では、既存の基準と現行結果を保持して再試行できます。モデル編集は可能ですが、通常どおり現行結果を無効にするので再実行が必要です。

ファイルの形式は次の version 1です。実データは省略せず、コンパクトな JSON で保存します。

```json
{
  "format": "blocksim.run",
  "version": 1,
  "model": {"version":1,"dt":0.01,"duration":1,"blocks":[],"edges":[]},
  "result": {"times":[],"traces":[],"solver":"..."}
}
```

上の例は構造の説明用です。実行できるモデルとその完全な計算結果が必要です。未知のフィールド・バージョン、非有限／非数値の記録値、モデルと異なる記録数・時刻・Scope・信号幅を拒否します。ファイル全体は64 MiB、内部のモデル JSON は1 MBまでで、従来の最大256展開ブロック・幅64・100000区間・200万記録成分・2000万ブロック成分ステップも適用します。ファイルのサイズ上限は本文を読む前に確認します。

一致の確認は補間・丸め・誤差許容を使いません。現在の WASM で異なる結果になるファイルは取り込めず、モデル設定やソルバ情報だけを変更した結果も拒否します。モデル JSON と実行結果ファイルはそれぞれ専用の読み込み欄を使います。

## コピー・複製と表示倍率

「すべて選択」または Ctrl/Cmd+A は表示中の階層を選択します。「コピー」／Ctrl/Cmd+C はブロックと選択内の接続をスナップショットとして保持し、「貼り付け」／Ctrl/Cmd+V で表示中の階層に追加します。「複製」／Ctrl/Cmd+D は選択をその場で複製します。入力欄のショートカットは通常の文字編集を優先します。

クリップボードは同じブラウザタブのエディタ内だけで使い、ページ再読み込みで消えます。OS クリップボードの読み書きは行いません。選択外との接続は含めず、コピー後に元の設定を変更してもスナップショットは変わりません。境界 Input / Output を含む選択は拒否します。サブシステム本体は内部モデルを含めて複製できます。ID を衝突しない値に変更し、内部接続と相対配置を保持します。追加した Scope の同名ラベルには ID を併記します。

貼り付け先の刻み幅・計算方式・RK45 の許容誤差／内部刻みが異なる場合は拒否します。内部モデルの終了時刻は貼り付け先に合わせ、Step 時刻や離散周期などの設定値は保持します。上限を超える追加は履歴に反映せず拒否します。貼り付け位置は通常40ずつ右下にずらし、連続した貼り付けでは移動量を増やします。座標上限付近では全ブロックに同じ移動量を適用します。外部入力は必要に応じてつなぎ直してください。追加操作は1回の Undo で戻せます。

縮小・拡大は2〜200%で、「100% 表示」で戻せます。「全体を表示」は表示中の階層のブロック、ポート、フィードバック線を収めます。スクロールで移動できます。表示倍率はモデルの保存・数値計算・履歴・未保存判定に影響しません。ドラッグ量と配線プレビューは倍率を考慮してモデル座標へ変換します。

## モデル診断

「モデルを確認」で「モデル診断」を開き、実行前の問題を一覧表示します。モデルの編集・Undo／Redo・復元でも更新します。未接続の入力はポートごとに、幅不一致は接続元と対象の入力を示します。Mux の幅合計、Selector の範囲、代数ループ、Scope の不足、計算量・記録量の上限も確認します。一度に50件表示し、「前の問題」「次の問題」で全件を確認できます。

対象ブロックと入力ポートを強調表示し、一覧の「表示」でその階層へ移動して設定を開き、対象の入力にフォーカスします。内部 Input の問題には「親の入力」も表示し、対応するサブシステムの入力へ移動できます。「接続元」で信号を供給するブロックも確認できます。内部の問題があるサブシステムには件数を表示します。代数ループでは、循環に参加するブロックを示し、下流の Scope は原因として強調しません。

診断と移動はモデル・位置・数値結果・履歴・未保存判定を変えません。実行前の問題があるモデルはワーカーを起動せず、診断を開きます。作成途中の保存は引き続き可能です。診断一覧や選択は保存データに含めず、モデルから計算し直します。

構造・パラメータが不正で解析を続けられない場合は、全体の問題として最初のエラーを表示します。空のモデル・Scope の不足には追加操作、計算量・記録量の上限には時間設定への移動を案内します。実行前チェックは数値の安定性を保証しません。オーバーフローやワーカー起動失敗は計算中のエラーとして表示し、メッセージから対象ブロックを推測しません。

## ブロック検索

「ブロックを検索」を開くか、入力欄以外で Ctrl/Cmd+K を押して検索できます。ブロックの名前・ID・種類、祖先サブシステムの名前・IDを部分一致で調べます。空白で区切った語はすべて一致する必要があります。大文字／小文字や全角英字は正規化して扱い、正規表現は使いません。種類だけで絞り込むこともできます。

検索範囲はモデル全体（内部を含む）か、表示中の階層だけを選べます。境界 Input / Output も対象です。同じローカル ID を持つ内部ブロックは `amplifier/gain` のようなパスで区別します。結果はパス順に並び、モデルの件数内で全件を表示します。一覧はスクロールできます。

結果のボタンで対象へ、検索欄の Enter で最初の結果へ移動し、その階層を開いて対象だけを選択、前面表示して設定を開きます。対象が収まる100%以下の倍率で中央付近へ移動するので、遠い位置・重なったブロックも確認できます。検索パネルを Escape で閉じられますが、配線中は配線のキャンセルを優先します。「検索をクリア」は語と種類を解除し、検索範囲を保持します。

検索と移動はモデル、位置、数値結果、変更履歴、未保存判定を変えません。移動時は配線中の状態と選択した接続を解除します。検索語・範囲・種類は同じエディタ内で保持し、モデル JSON やブラウザ保存には含めません。改名・削除・Undo・置き換え・復元の後は現在のモデルから結果を更新します。検索から開いた設定の変更は通常のモデル編集として Undo と保存の対象になります。

## 自動配置

「自動配置」は表示中の階層全体を整理し、その範囲を全体表示します。選択したブロックだけを配置する機能ではありません。サブシステム本体を配置しても内部の位置は変えず、内部を開けばその階層だけを配置できます。

信号の流れを左から右へ並べ、フィードバックを持つまとまりでは外部入力を起点として循環内のブロックを並べます。分岐先は実際の接続元に近い列へ置きます。独立したモデルは縦の別領域に分けるので、コピー／貼り付けで重なったモデルも整理できます。ID と接続から配置を決め、元の座標やブロック配列の順序に依存しません。ポート数に応じた高さと戻り線の余白を取ります。

長い直列モデルや多数の独立ブロックが座標上限を超える場合は、0〜10000に収まる格子配置へ切り替え、画面に表示します。格子では信号の並びが折り返します。未接続の作成途中モデルやループを持つモデルも配置できますが、実行時の検証条件は変わりません。

変更はブロック位置だけです。接続、ID、表示名、パラメータ、内部モデル、時計、記録系列の順序を保持します。モデル変更として結果を無効化し、1回の Undo で配置前へ戻せます。配置済みモデルでは履歴・計算結果・未保存判定を変えません。位置は既存の JSON・ブラウザ保存に含まれます。線の交差や交差数の最小化、任意の長いラベルでの完全な重なり防止は保証しません。

## ブロック

| ブロック | 動作 |
|---|---|
| Constant | 指定ベクトルの定数 |
| Step | 指定時刻に before から after へ変更 |
| Sine | 指定振幅・Hz・位相・オフセットの正弦波（各成分に同じ値） |
| Gain | 各成分をスカラー倍 |
| Sum | 同じ幅の入力を指定係数で加算 |
| Product | 同じ幅の入力を成分ごとに乗算 |
| Saturation | 各成分を任意の上下限で制限 |
| Integrator | 連続積分、ベクトルの初期状態 |
| TransferFunction | 0〜8次の実係数連続伝達関数、各成分を独立に処理 |
| FirstOrder | `y'=(gain*u-y)/tau`、ベクトルの初期状態 |
| Unit Delay | 指定周期の1サンプル遅延、初期出力 |
| PID | 連続／離散 PID、任意制限と条件付き積分、成分ごとに独立した状態 |
| Mux | 複数のベクトルを順番に連結 |
| Selector | 指定インデックスの成分を抽出（並べ替え・重複も可能） |
| Scope | 接続した信号の各成分を記録 |
| Subsystem | Input / Output を境界とした内部モデル |

通常は入力と出力の信号幅を明示的に一致させます。暗黙のスカラー・ベクトルの拡張は行いません。Mux の出力幅は入力幅の合計、Selector の出力幅はインデックス数です。

## サブシステム

チェックボックスで複数選択し「サブシステム化」すると、外部との接続を Input / Output 境界に変換します。外部への出力接続がある選択が対象です。同じ出力からの分岐は1つの出力境界を共有します。Input / Output 境界そのものはグループ化しません。

「内部を編集」またはダブルクリックで内部を編集し、パンくずで親へ戻ります。複数入出力・異なるベクトル幅・入れ子に対応します。Input / Output のポートはそれぞれ0から連続させる必要があります。実行時は階層を展開し、境界も含めた接続幅とループを検証します。内部の Scope は `subsystem-id/scope-id` のようなパスで記録します。現在は最大8階層です。

サブシステムを1つ選び「グループ解除」で内部ブロックを親へ戻せます。境界 Input / Output は取り除き、外部との接続・分岐・フィードバック・境界同士の直結をつなぎ直します。内部の状態設定・ベクトル幅・入れ子モデルを保持し、未接続の入力は未接続のまま残します。境界だけの循環や多重入力は解除を拒否します。

展開したブロック ID は親との衝突を避けて変更します。内部 Scope の記録 ID も変わりますが、ラベルと信号値は保持します。位置はサブシステムの場所を基準に移し、0〜10000に制限します。操作は1回の Undo で戻せます。

## 時計とソルバ

TransferFunction と連続線形モデルの Bode 解析は [周波数応答仕様](frequency.md) を参照してください。

可変刻み RK45・計算統計・パラメータ掃引の詳細と再現モデルは [数値計算と掃引](numerics.md) を参照してください。`solver` を省略したモデルは従来と同じ RK4 と結果 JSON を維持します。

モデル全体の基準刻み `dt`、終了時刻 `duration` を設定します。終了時刻は刻みの整数倍に限定します。内部モデルの時計もルートに合わせます。

- Integrator、FirstOrder、TransferFunction、連続 PID の状態を、結合した系として RK4 または RK45 で積分します。
- Step の切り替えが刻みの途中にある場合は、その時刻で区間を分割します。切り替え直前の積分端点では左極限、直後は新しい値を評価します。
- 離散 PID / Delay の周期は基準刻みの整数倍。各ブロックは指定した周期で更新し、その間の出力を保持します。
- 同じ時刻の Delay はすべて前周期の保留入力を出力へ反映してから、直接伝達ブロックをトポロジー順で評価します。最後に Delay の入力を次周期用に取得します。
- 離散 PID はヒット時に更新する直接伝達ブロックです。離散 PID 同士は接続順に評価します。直接伝達だけのループは許可せず、Integrator / FirstOrder / Delay / 厳密にプロパーな TransferFunction でループを切ります。
- `t=0` で離散 PID を初回更新し、Delay は初期値を出力します。終了時刻も記録点なので、周期が一致すればその時刻の離散更新を行います。PID Lab の終了点で更新しない仕様とは異なるため、同じ終端時刻の制御出力だけは一致を仮定しません。

固定刻み RK4 の連続系は `dt <= tau/2`（FirstOrder）、`dt <= derivative_tau/2`（連続 PID）を要求します。任意のゲイン・フィードバックの安定性を保証する条件ではありません。非有限な信号や状態はブロック ID・時刻を含むエラーとして返します。

作成途中の保存用 `normalize_graph` は未接続を許可します。実行用 `validate_graph` / `run_graph` は全入力、幅、代数ループ、Scope の存在を検証します。最大256展開ブロック、信号幅64、100000区間、200万記録成分、2000万ブロック成分ステップを上限とします。複数 Scope は記録予算を共有します。

WASM の `diagnose_graph(model_json)` は同じ実行前検証を行い、JSON 文字列を返します。Rust の `graph::diagnose_graph(&model)` は `GraphValidation` を返します。計算状態や時系列を確保せず、`runnable` は問題がない場合だけ `true` です。ブロック ID は階層を展開したパス、`port` は入力番号、`source_id` は接続元で、該当しない項目は `null` です。JSON 自体が不正・1 MB超過の場合は従来の API と同様にエラーを返します。

```json
{
  "runnable": false,
  "diagnostics": [
    {"code":"unconnected_input","message":"amplifier/in:0: unconnected input","block_id":"amplifier/in","port":0,"source_id":null}
  ]
}
```

コードは `structure`、`empty_graph`、`duplicate_input`、`unconnected_input`、`signal_width`、`mux_width`、`selector_index`、`algebraic_loop`、`missing_scope`、`work_limit`、`recording_limit` です。GUI の `runtime_error` は計算後の表示用で、診断 API の返却には含みません。

## 保存とサンプル

グラフの保存形式は `{version:2, graph:{version:1,dt,duration,blocks,edges}}`。モデル単体の JSON も読み込めます。ブロック位置、ラベル、パラメータ、接続、階層、時計・計算方式・RK45 の設定を保存します。未接続の作成途中モデルも保存できますが、実行には接続の修正が必要です。実行中の状態は保存しません。

グラフの localStorage キーは `blocksim.graph.v2`。従来の PID Lab の `blocksim.document.v1` と分け、既存の保存設定を上書きしません。「読み込み方法」で置き換え／追加を選べます。追加では既存ブロック・接続・基準刻み・終了時刻を保持し、取り込むブロックには衝突しない ID を付けて接続も更新します。刻み幅が異なるモデルは拒否します。追加するモデルの Step 時刻などのパラメータは変更しないので、必要なら追加後に既存の終了時刻を調整してください。追加操作も Undo／Redo 対象です。同名の Scope は記録 ID を併記して区別します。

画面にモデルの未保存変更を表示します。保存・復元・起動時のモデルと比較するため、Undo で同じモデルへ戻すと「変更なし」になります。コピー、選択、ズーム、計算では未保存になりません。サンプル、新規モデル、置き換え読み込み、保存モデルの復元で変更を失う場合は確認し、中止するとモデルを維持します。不正な JSON は確認前に拒否します。追加読み込みはモデルを残すので置き換えの確認はありません。

未保存変更があるページの離脱／再読み込みではブラウザ標準の確認を要求します。ブラウザ側のユーザー操作要件などに従うため、確認表示はブラウザが制御します。PID Lab へのタブ切り替えはモデルを維持します。「モデル JSON」の書き出しはブラウザ内の保存基準を変更しません。この判定はエディタのモデルに対するもので、未適用の設定欄や PID Lab の変更を追跡するものではありません。

未知のフィールド、不正なバージョン、1 MBを超える設定ファイルを拒否します。不正な保存ファイルを自動上書きしません。

| サンプル | 用途 |
|---|---|
| `samples/graphs/continuous-pid.json` | 既存の連続 PID 復帰実験を一般ブロック図で再現 |
| `samples/graphs/mixed-pid.json` | 50 ms の離散 PID、連続プラント、100 ms の Delay 観測 |
| `samples/graphs/vector.json` | 3成分の Gain / Saturation / Selector、複数系列 |
| `samples/graphs/subsystem.json` | 正弦波入力と内部 Gain を持つ Subsystem |

ブラウザ以外でも実行できます。

```bash
source scripts/rust-env.sh
cargo run --locked -p blocksim-core --example graph -- samples/graphs/mixed-pid.json
# 第2引数を指定すると数値結果を JSON ファイルへ保存します。
cargo run --locked -p blocksim-core --example graph -- samples/graphs/vector.json /tmp/blocksim-vector-result.json
```

## 現在の範囲

固定／可変刻みの常微分方程式と同期した離散処理、連続 LTI の周波数応答を扱います。剛性ソルバ、DAE、ゼロクロッシング一般処理、任意の非整数周期、代数ループ解法、物理領域ライブラリ、Simulink ファイル互換、コード生成、共同編集は未実装です。配線のドラッグ接続、OS クリップボード経由のモデル共有は今後の改善対象です。現在の直接配線はポートを順にクリックする方式です。
