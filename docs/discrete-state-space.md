# 同一周期の離散状態空間・単位円の安定性

状態空間パネルの「解析領域」を **離散系・同一周期（z平面）** にします。選択Scope成分の祖先の現在の接続から、サンプル時刻の `x[k+1]=Ax[k]+Bu[k]、y[k]=Cx[k]+Du[k]` を取り出します。固有値は無次元のz平面へ表示し、漸近安定は単位円の内側を基準に数値判定します。連続系のs平面の座標・単位とは別です。

## 対象と更新順序

同じ `sample_time` のDelay・Discrete TransferFunction・無制限の離散PIDと、Gain／Sum、静的TransferFunction、入力1本のProduct、無制限Saturation、Scope、階層の入出力・Mux／Selectorを扱います。関連128成分変数、最大8状態。連続状態、制限付きPID／Saturation、多入力Product、異なる周期、代数ループは解析前に拒否します。時計は通常の実行検証でdtの整数倍であることを確認し、関連ブロックのsample_timeは値自体も完全一致が必要です。離散時計を持たない静的な系だけなら表示周期はモデルdtです。次数0のDiscrete TransferFunctionも設定周期を使います。

選択Scopeに無関係な枝・成分は除外するため、全モデルの安定性ではありません。無関係な枝に連続状態・異なる周期があっても解析対象に含めません。全モデルの構造・実行予算の検証は維持します。他の信号源の変動と初期条件はゼロ、選択信号源の振幅・波形は行列を変えません。状態削除・極零相殺・最小実現は行いません。

状態x[k]は、そのサンプルのPID更新前の状態です。Delayは前のサンプルの入力を出力します。PIDは既存のトポロジー順で更新し、その直後の出力を下流へ渡します。全Delayの次の入力と離散伝達関数の次状態は、同じ評価済み信号から一斉に採取します。離散伝達関数は更新前のcompanion状態と現在の入力で出力します（[係数と同期仕様](discrete-transfer.md)）。行列の抽出では実際のPID `step` とブロック評価式を単位状態・単位入力で使い、有限差分は使いません。y[k]はそのPID更新後、次のDelay／離散伝達関数の状態コミット前のScope値です。

Delayは保持入力1状態、離散PIDは重み付き積分I・前回誤差e_prev・微分フィルターdの3状態です。Tsを周期、τを微分フィルター時定数とすると、無制限PIDは以下を使います。

```text
d' = (τ d + e − e_prev) / (τ + Ts)
I' = I + Ki e Ts
e_prev' = e
u = Kp e + Kd d' + I'
```

KiやKdがゼロでも状態を残します。Ki=0の積分Iは変わらず、z=1の内部モードが残るため、出力が減衰しても内部実現を漸近安定とは扱いません。サンプル間のPID保持出力を別の冗長状態として加えず、サンプル時刻だけの実現です。連続プラントとの混在系や周期間の応答を近似して解析する機能ではありません。

## 数値判定

行列の尺度、Faddeev–LeVerrierの特性多項式、Cayley–Hamilton残差、全根の多項式残差・係数再構成と独立した行列式残差は [連続状態空間](state-space.md#行列と数値評価) と同じです。表示する固有値は元のAの値で、連続系の1/s・rad/sへ変換しません。

安定性は近似固有値の絶対値だけで決めません。検証した特性多項式から元のp(z)を正の倍率で正規化し、`q(s)=(1−s)^n p((1+s)/(1−s))` を作ります。`Re(s)>0 ⇔ |z|>1` なので、実Routh表から単位円の外の極の個数を求めます。極の座標の求根が未解決でも、この独立判定が有効な場合は表示します。

z=−1では双一次変換の最高次係数がゼロになります。完全なゼロの次数低下は境界モードとして保持し、残りに不安定モードがあれば不安定を優先します。z=+1や他の円上の根も安定へ置き換えません。双一次変換の係数の非ゼロ和が各項の絶対値和の1e−10以下なら境界／近傍・個数未確定です。対数で元の係数を復元する際の指数差が−700未満、非有限値・特性多項式の検証失敗は判定不能。Routh表の小さいピボットへ任意のepsilonは加えません。

境界／近傍、求根未解決、個数未確定、判定不能は区別します。例えばKi=Kd=0のPIDを含む検証モデルでは、ほぼゼロの特性係数が厳しい根の再構成検証を通らず、根の一覧を空にして未解決と表示します。行列のI行がI'=Iであることは保持し、双一次係数も境界／近傍と判定します。部分的な根や都合のよい相殺は返しません。

これは最大8状態の浮動小数点評価です。特に円の近傍、重根・近接根、非正規行列・極端な尺度で、座標誤差や厳密な安定性の証明を保証しません。

## 保存・出力

既存の `blocksim.state-space` version1へ任意の `domain:"discrete"` を加えて保存します。省略時は従来の連続系で、明示したcontinuousも連続系として扱います。未知の値・キーは拒否します。離散／連続の旧モデル形式は変えません。設定はモデル・信号源／Scope／成分を含み1 MBまで、読み込みでは通常の未保存確認でモデルを置き換え、その後に解析します。

CSVは離散系で `real_dimensionless、imag_dimensionless、outside_unit_circle_poles` を使い、周期のsample_time行、全行列・状態・極・残差・注記を保存します。結果JSONにはsample_timeと同じ計算済み結果を保存します。個数不明は空欄／未確定です。連続系の旧CSV列・結果形式は維持します。フォームで解析領域を切り替えても過去の計算結果の座標・ラベル・CSVを付け替えません。Worker中止、古い返答・遅延ファイル、同時実行防止、モデル編集／Undoでの無効化は連続系と共通です。

## 接続済みサンプル

[feedback-plan.json](../samples/discrete/feedback-plan.json) を読み込むか、サンプル「離散負帰還・単位円の極」を開いて解析領域を離散へ変更します。Ts=0.1s、記録dt=0.02s、10秒・501点です。2段DelayとSumの実際の接続で以下を実行します。

```text
x₁[k+1] = u[k] + ρ x₁[k] − ρ² x₂[k]
x₂[k+1] = x₁[k]
y[k] = x₁[k]
```

極は `ρ exp(±jπ/3)`。ρ=0.8で安定、1で境界、1.2で単位円外2個・不安定になります。Sumの係数を `[1,ρ,−ρ²]` に変更して比較します。`cargo run --locked -p blocksim-core --example discrete_state_space` は独立した有限等比級数のStep応答式を、501記録点・サンプル間の保持も含む実シミュレーターと比較します。

| ρ | 最大極誤差 | 最大時間応答誤差 | 最大誤差/(1+解析出力絶対値) |
|---:|---:|---:|---:|
| 0.8 | 5.56e−17未満 | 6.67e−16未満 | 3.05e−16未満 |
| 1 | 0 | 1.85e−14未満 | 9.88e−15未満 |
| 1.2 | 2.23e−16未満 | 8.26e−7未満 | 1.06e−13未満 |

詳細は [検証JSON](discrete-state-space-validation.json)。不安定ケースの最大出力は約5.57e7です。有限の10秒窓の値で、任意のモデルや期間で同じ精度を保証しません。
