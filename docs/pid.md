# PID 数値仕様

## 連続 PID

誤差 `e=r-y`、重み付き積分状態 `I`、フィルタ状態 `F` に対して、

```text
F'    = (e - F) / derivative_tau
u_raw = Kp * e + I + Kd * F'
I'    = Ki * e                         (通常)
u     = clamp(u_raw, lower, upper)
```

AW 有効なら、`u_raw >= upper && Ki*e > 0` または `u_raw <= lower && Ki*e < 0` のときだけ `I'=0` にします。判定は未制限出力と積分項の変化方向に基づきます。負の Ki も同じ規則です。戻す方向の積分と微分フィルタは飽和中も更新します。制限なしでは凍結条件は成立しません。

`ContinuousPid::advance` は誤差を保持して状態を RK4 更新します。閉ループ実験では PID とプラントの全状態を同じ RK4 ステージで評価します。初期 `I=F=0`、微分は誤差に対して行うため目標値変更時の derivative kick を含みます。`derivative_tau > 0` は必須です。

切り替え面を含む非滑らかな系を固定刻みで近似しているため、積分状態に小さい数値超過が起こる場合があります。出力のクランプは各ステージと記録点で必ず適用します。初期実装の閉ループ実験は `dt <= min(plant_tau, derivative_tau)/2` を要求します。これは時間分解能のガードであり、任意ゲインの安定性を保証する条件ではありません。

## 離散 PID

```text
D[n]       = (tau * D[n-1] + e[n] - e[n-1]) / (tau + dt)
change     = Ki * e[n] * dt
I_candidate= I[n-1] + change
u_candidate= Kp * e[n] + I_candidate + Kd * D[n]
```

AW 有効時、候補出力が上限以上で `change>0`、または下限以下で `change<0` なら、そのサンプルの積分更新を拒否します。それ以外は候補を受け入れます。候補を用いることで、その更新自体が飽和を発生させる場合も凍結します。出力は採用した積分状態から計算してクランプします。`e[-1]=D[-1]=I[-1]=0`。微分フィルタは後退 Euler、積分はサンプルごとの矩形更新です。

## プラント・目標変更・メトリクス

実験は単位負帰還、一次遅れプラント `y'=(plant_gain*u-y)/plant_tau` です。目標値は指定刻みでサンプルし、`step_time` 以後の最初の記録点で切り替えます。刻みの中では保持します。連続 PID は結合 RK4、離散 PID は制御出力を保持してプラントを解析的に更新します。終了時刻が刻みで割り切れない場合は最後の区間を短縮します。離散の終了記録点では制御器を再更新せず、直前に保持した制御出力を記録します。

- `control` は制限された PID 出力、`output` はプラント出力です。制限範囲が適用されるのは PID 出力です。
- 復帰 IAE は変更を観測してから終了までの `|y-final_reference|` の台形積分です。
- 整定時間は、その後の全記録点が許容誤差内となる最初の記録点です。観測期間外の挙動を予測しません。期間内に整定しなければ `null`。
- 上限解除時間は、変更後に `control < upper - 1e-9` となる最初の記録点です。上限なし／解除未達は `null`。変更時に既に解除されていれば 0。
- 最大積分項は全記録点の `max(|I|)` です。

モデル入力は有限数値、正の時間パラメータ、順序の正しい制限を要求し、最大100000区間に制限します。大きすぎるゲインによる数値オーバーフローもエラーとして返します。

## Saturation と保存互換性

Saturation は同じ上下限を各入力要素に独立適用します。上限／下限は `null` で未設定、両方 `null` は恒等写像、同じ値なら固定出力です。NaN・無限大は拒否します。Rust はスカラーと任意長ベクトル、GUI は最大4096要素の JSON 配列に対応します。

PID の JSON で `limits` を省略すると両側無制限、`anti_windup` を省略すると `false`。未知のモデルフィールドはタイプミスとして拒否します。GUI の保存形式は `{version:1, model:..., saturation:{input:[],limits:...}}`。モデル単体の JSON も読み込めます。Rust/WASM の正規化を通してモデルを復元し、Saturation も有限数値・上下限を検証します。未対応の保存形式バージョンは拒否します。
