# 比較区間を許容差で判定

行列応答比較の「比較区間を許容差で判定」を開き、絶対・相対許容差を指定して「許容差で判定する」を有効にします。[評価区間](matrix-range.md)の両端を含む全取得点・全出力に、次の判定を適用します。

`|離散値−連続値| ≤ 絶対許容差＋相対許容差×|連続値|`

連続値が基準です。等号を含み、値の符号には依存しません。連続値が0なら絶対許容差だけを使います。絶対・相対は非負の有限値で、両方0なら浮動小数点の取得値が完全一致する点だけが許容差内になります。表示の丸めや間引いた線ではなく、実行済みの生値を判定します。

初期状態では判定を無効にします。入力欄の初期値は絶対1e−6・相対1e−3ですが、用途に適した設定を利用者が選ぶための値です。RK45の内部許容差を変更する操作ではありません。全出力へ同じ設定を適用します。絶対許容差は出力と同じ単位、相対許容差は無次元です。出力の単位・尺度が異なる場合は、共通の絶対許容差が適切かを確認してください。

判定表は各出力の許容差内／超過あり、超過した取得点の数、最初・最後の超過サンプルを表示します。全体の超過数は**成分点の数**で、同じサンプルで2出力が超過すると2と数えます。最初の超過点へのボタンは、早いサンプル・同じ点なら小さい出力番号を選びます。各出力のボタンもあります。カーソルと表示出力を切り替え、元の取得時刻・実入力・連続／離散・符号付きΔを確認できます。超過がなければ移動ボタンを無効にします。

開始・終了は0〜最終点の整数、開始≦終了です。1点区間も使えます。判定は区間の変更と許容差の有効な編集に追随します。未実行の比較条件を編集しても、表示中の実行済み結果を判定します。元モデル・Scope・編集履歴・実行条件・全結果／区間ファイルを変更せず、WASMを再実行しません。最大2001点×8出力を対象にします。

空欄・負数・非有限の許容差では、同じ結果・区間の前回判定を保持し、設定／判定の保存と超過点への移動を無効にします。有効な値に修復すると再判定します。区間が不正、区間の既存指標が有限範囲を超える、結果が解除される、または判定を無効にすると表と判定メタデータを解除します。無効な許容差のまま結果や区間が変わった場合も、前回と取り違えないため表を解除します。計算中は前回結果を判定・確認でき、ファイル保存／読み込みは完了を待ちます。中止・失敗は前回結果と現在の許容差・閲覧位置を保持します。

## 設定と判定結果の保存

「許容差設定 JSON」は `blocksim.matrix-comparison-tolerance-settings`、version1で、`enabled`・`absolute`・`relative`を保存します。比較完了前にも設定できます。未知・欠落・不正項目、非対応バージョン、非booleanの有効値、負数・非有限値、100KBを超える文字数／UTF-8／File.sizeを拒否して前回設定を保持します。

設定の遅延読み込み中にカーソル・出力・区間だけを操作しても読み込みを継続します。許容差を編集したり計算を開始したりした場合は、途中で中止していても読み込みを破棄します。別のファイルを選ぶと新しい要求を優先します。モデル／選択変更で設定欄が外れた場合、外れた欄の読み込み結果を適用しません。

「区間判定 JSON」は `blocksim.matrix-comparison-tolerance-result`、version1で、判定式・現在の許容差・前回実行した比較条件と変換結果・区間の判定表と超過数・元のサンプル番号・区間の全生値を保存します。元の番号を0から振り直しません。外部での確認用で、設定や比較結果として読み戻す形式ではありません。今回の判定値を再確認するには、比較の全結果または作業状態と、許容差設定をそれぞれ保存・復元します。

既存の比較条件／全結果／区間／[作業状態JSON](matrix-session.md)の形式は変更しません。許容差は独立した設定で、作業状態ファイルには含まれません。作業状態の復元は現在の許容差を保持し、復元した区間へ適用します。画面再読込・モデル／選択変更で設定欄が作り直されると初期値へ戻るため、再利用する値は許容差設定JSONで保存してください。

## 数値と判定の範囲

通常は差分と許容値を直接比較します。大きな有限値で差分や許容値の計算がオーバーフローする場合、有限の尺度で両辺を正規化し、`Infinity ≤ Infinity`だけで許容差内にしません。IEEE 754倍精度の丸め・最小値の限界は残ります。この判定用補助関数の極端な数値の検査は、WASMがその条件の比較結果を生成できる保証ではありません。アプリでは既存の取得値・指標・計算予算の検査を維持します。

許容差内という表示は、利用者が選んだ基準へ**取得点だけ**が収まったことを示します。点と点の間の真の誤差、一般的な精度・安定性、適切な閾値の選び方、変換方法の妥当性を保証するものではありません。[実測値](matrix-tolerance-validation.json)と[検証記録](validation.md)を参照してください。
