# 行列応答比較の結果を読み戻す

「比較結果 JSON」で保存した全結果を、「比較結果を読み込む」で再度開けます。現在選択した連続StateSpaceの行列と初期状態が、ファイルの比較条件と一致していることが必要です。モデル自体はファイルへ含めないため、別セッションでは元のモデルを開いて対象行列を選んでください。

読み込みは現在のWASMで同じ条件を再計算し、全取得点の入力・連続／離散出力・時刻、全出力の指標、変換行列・初期値・診断項目まで完全一致した場合に復元します。一部の点・成分だけの照合や、許容差で違いを丸めて受け入れる操作ではありません。JSONのオブジェクト項目順だけの違いは受け入れます。

成功すると離散化方式・周期・プリワープ、入力の種別・ベクトル・表・繰り返し、比較点数を前回実行条件へ戻し、全指標と波形を表示します。カーソルは0、表示出力は0、評価区間は全区間から確認できます。元のモデル・接続・履歴・完了Scope結果は保持し、変換行列をモデルへ自動適用しません。

比較設定JSONは条件だけ、比較結果JSONは全取得値を含むファイルです。[区間結果JSON](matrix-range.md)は全取得点を含まないため、この読み込みでは受け付けません。既存の結果保存形式 `blocksim.matrix-comparison-result`／version1を使い、保存内容を変更していません。

## 検証と中止

ファイル上限は8 MiB、比較条件の上限は従来どおり100 KB。最大2001点・入力／出力各8・状態16の既存制限を使います。次を確認してから再計算します。

- 保存形式・バージョン・項目名、全行の点数・信号幅・有限値。
- 時刻は実行時の取得時計 `k×10×(Ts/10)` と厳密一致し、初回0から単調増加。
- 全実入力は実行条件のstep／系列／最終行保持／繰り返しと一致。
- 全区間とstep変更後の全指標は、保存した取得値から集計した値へ厳密一致。系列にstepだけの時刻／指標を混在させません。
- 変換要求、行列の寸法・有限値、初期値・診断項目の形式。方式は要求内のenum、変換結果のmethodは説明文です。

取得値と指標の整合性だけでは正しい実行結果と断定しません。Workerで両モデルを再実行して、変換係数や、指標まで整合させた出力の改変も検出します。各モデル1000万、合計最大2000万block-component evaluationsの既存予算を増やしません。

「比較を中止」で読み込み後の再計算を止められます。不正ファイル、選択行列の不一致、再計算との不一致、予算停止、中止は、前回結果・カーソル・区間・現在の比較設定を保持します。成功するまで設定を部分的に復元しません。

ファイル読み取り中に比較条件・変換条件・モデル・選択が変わった場合、別の実行を開始／完了した場合、より新しいファイル読み込みを始めた場合は、古い読み込みを破棄します。カーソル・出力成分・区間の閲覧だけでは有効な読み取りを破棄しません。検証の実行中は他の実行・読み込み・変換を制限し、前回結果の閲覧を続けられます。Workerが終了するまで結果の書き出しは待ちます。

現在の実装との再計算一致は、外部ファイルの出所、別バージョン／OSの再現性、モデル全体や一般的な精度・安定性を保証するものではありません。WASMの演算が将来変更されて結果が異なる場合は、成功として読み戻しません。[検証記録](validation.md)に実際の結果と制限を残します。
