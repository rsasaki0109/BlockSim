# 複数入出力（MIMO）の線形解析

A・B・C・Dを直接指定する[StateSpaceブロック](matrix-block.md)で、連続・離散の複数入出力モデルを作成・実行できます。

ブロック図エディタの「複数入出力（MIMO）の状態空間 / 周波数応答」で、独立に変動させる信号源成分と、観測するScope成分を各1〜8個選択します。同じ側に同じ成分を重複して指定できません。同じブロックの異なる成分、階層内の完全なブロックIDも選べます。

連続系は `ẋ=Ax+Bu, y=Cx+Du`、同一周期離散系は `x[k+1]=Ax[k]+Bu[k], y[k]=Cx[k]+Du[k]` です。行列の並びは、状態一覧・入力選択順・出力選択順に従います。Bは状態×入力、Cは出力×状態、Dは出力×入力です。初期条件と選択していない信号源の変動はゼロとします。入力と出力の添字は0始まりです。

## 共通の状態を保つ

選択した全出力の祖先を、ブロックIDと成分の組で重複なしに統合します。複数の出力が同じ内部状態を見る場合も、その状態を1個として扱います。最大16状態・関連128成分変数です。各出力が個別には上限内でも、統合後に上限を超えると拒否します。

既存の状態空間解析と同じスカラー化・実行式の単位入力／単位状態を使います。有限差分、配線の切断、極零相殺、最小実現、状態削除は行いません。選択入力が祖先にない場合は対応するB列・D列がゼロですが、内部状態は残ります。選択していない出力の祖先、モデル全体の安定性を評価する機能ではありません。

離散系は選択出力の祖先全体で厳密に同じsample_timeを要求します。更新前のDelay・離散伝達関数状態と、サンプル時点のPID更新を使い、全Delay入力を同じ評価から同期して取得します。時間応答で使える混在周期や連続プラントとの混在を、離散線形解析で近似しません。制限付きPID、非線形ブロック、代数ループは従来どおり拒否します。

## 数値ランクと固有値

可制御性は `[B, AB, …, A^(n−1)B]`、可観測性は `[C; CA; …; CA^(n−1)]` の数値ランクを診断します。各入力列・各出力行を組み合わせた診断なので、1入力だけではランク不足でも、複数入力で数値フルランクになる場合があります。

Aの共通尺度、Krylov列の個別正規化、列ピボット、2回の再直交化を使います。閾値1e−10、近傍帯1e−12〜1e−8。ランク不足・閾値付近・未解決・動的状態なしを区別します。尺度変換・積で解像度を失う場合はランクnullで、0に置き換えません。入力・出力ゲインの絶対的な大きさや制御エネルギーは評価しません。詳細は[数値診断仕様](structural-analysis.md)を参照してください。

全内部状態の固有値・残差・安定性判定を保持します。数値ランクは厳密な可制御性・可観測性の証明ではありません。固有値の座標が検証済みでも、Routh表の未確定判定を安定に置き換えません。

## 入出力ごとの周波数応答

全入力と全出力の組に対して `H(s)=C(sI−A)^−1B+D`、離散系は `H(z)=C(zI−A)^−1B+D, z=exp(jωTs)` を計算します。行列の行尺度・ピボットと独立残差検証は既存の複素線形ソルバーを共有します。1e−9≤最小角周波数<最大角周波数≤1e9 rad/s、解像度のある対数グリッド2〜512点、離散系は最大ω≤π/Tsです。密な状態方程式の概算 `max(n,1)^3 × 点数 × 入力数` は20,000,000以下です。

GUIでは経路を切り替えてBode図と20点ずつの全取得値を確認できます。位相は−180〜180度の主値で、unwrapやMIMO安定余裕ではありません。零応答は複素値0・振幅0ですが、dBと位相は未定義です。特異・悪条件・非有限・残差失敗は該当入力と周波数の全出力で欠測にし、0や補間値を作りません。相殺した経路を特別扱いして内部特異点を隠しません。

## 保存・復元と互換性

専用設定JSONは `format: blocksim.mimo, version: 1`、modelとrequestを保存します。requestはinputs／outputs（blockとcomponent）、discrete、min_omega、max_omega、pointsです。1 MB以下、未知・不足・不正な項目を拒否します。読み込み前にモデルとネイティブ解析条件を検証し、失敗時は元モデルと完了結果を保持します。読み込み成功時は通常のモデル置換確認と編集履歴を使います。

結果JSONは行列・状態・全極・数値診断・全経路の全周波数点を含む書き出しです。CSVにも実行時のrequest、入出力の順序、全係数、状態順序、固有値、診断、周期、全経路の全点を含めます。現在のフォームや表示経路を変えても、完了した結果とCSVは実行時の条件を保ちます。結果JSONは設定の読み込み用ではありません。

解析は専用Workerで実行し、時間応答・掃引・他の解析・ファイル検証と実行ガードを共有します。中止・遅れて届いたWorker結果・古い非同期ファイル読み込みは直前の結果やモデルを上書きしません。

既存の1成分のStateSpaceRequest／結果／設定形式、モデルJSON、PIDの既定値、時間応答は維持します。単独の伝達関数次数0〜8と変換法の制約も変わりません。

## 2入力・2出力サンプル

[連続サンプル](../samples/mimo/continuous-plan.json)では `x1′=−x1+u1+u2, x2′=−x2+u1−u2`、`y1=x1+2x2+0.25u1, y2=x1−x2+0.5u2` です。A=−I、B=[[1,1],[1,−1]]、C=[[1,2],[1,−1]]、D=[[0.25,0],[0,0.5]]。F=1/(s+1)とすると、全4経路は `[[3F+0.25, −F],[0, 2F+0.5]]` です。

両状態の極は同じ−1なので、各入力だけの数値ランクは1、2入力を合わせると2です。共有状態を出力ごとに複製せず、零伝達の経路も全内部極も残します。u1=1／u2=2のStepでは `y1=1−exp(−t)+0.25`、`y2=4(1−exp(−t))+1` が独立式です。

[離散サンプル](../samples/mimo/discrete-plan.json)は両状態をTs=0.1sのDelayへ変え、A=0・F=1/z。最初の更新前はy1=0.25／y2=1、0.1秒以降はy1=1.25／y2=5です。設定ファイルを読み込むか、画面のサンプルボタンで試せます。数値・互換性・保存復元の検証と途中の失敗は[検証記録](validation.md)に記載します。
