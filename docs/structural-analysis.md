# 16状態の解析と数値ランク診断

接続された連続線形部分と、同一周期の離散線形部分について、選択Scope成分の祖先を最大16状態まで解析します。関連成分変数の上限128、密行列の計算予算、非線形・混在周期・代数ループの拒否は維持します。単独のTransferFunctionの係数次数は従来どおり0〜8です。

GUIの「接続された線形部分の状態空間 / 安定性」へ可制御性・可観測性の数値ランクを追加しました。結果JSONの追加項目`structure`、CSVの`controllability_rank`／`observability_rank`にも、実行した入力・Scope成分、状態数、数値ランク、閾値、ピボットノルム、判定を保存します。モデル・解析設定の形式は変更せず、古い設定ファイルを読み込めます。追加診断のない古い結果では従来のCSVを出力し、Rustでの結果読み込みも追加項目なしを許します。

## 診断の意味

現在の接続から抽出したA・B・Cに対し、単一入力の可制御性行列`[B, AB, …, A^(n−1)B]`と、単一出力の可観測性行列`[C; CA; …; CA^(n−1)]`の数値ランクを調べます。

行列Aを共通の正の尺度で正規化し、Krylov列を個別に正規化して、列ピボットと2回の再直交化で診断します。巨大な行列べき乗を直接作りません。B・Cの絶対的なゲイン、入力エネルギー、制御しやすさは評価しません。状態の座標や相対尺度には依存します。

数値閾値は1e−10。その1/100〜100倍（1e−12〜1e−8）にピボットが入った場合は、暫定ランクとともに「閾値付近・未確定」を表示します。

| 判定 | 表示と意味 |
|---|---|
| full_numerical_rank | 数値フルランク。閾値から離れた正規化行列の診断 |
| numerical_rank_deficient | 数値的にランク不足。厳密な非可制御・非可観測の証明ではない |
| near_threshold | 閾値付近・未確定。ランク値から厳密に断定しない |
| unresolved | 尺度変換・積などで有限精度を失う場合。ランクをnullにし、0と扱わない |
| no_states | 動的状態なし。ランク0／状態0 |

判定にかかわらず、元の状態・固有値を削除しません。極零相殺、最小実現、MIMO全体の診断は行いません。選択入力がScopeの祖先にない場合はBが0で、可制御性の数値ランクも0になります。出力ゲイン0で内部状態が見えなくても、状態と内部安定性は残します。

## 16状態のサンプル

| サンプル | 時間応答・周波数応答の独立式 | 固有値 |
|---|---|---|
| [16積分器](../samples/state-space/sixteen-integrators-plan.json) | Step応答`t^16/16!`、周波数応答`1/(jω)^16` | 0が16個、境界 |
| [16一次遅れ](../samples/state-space/sixteen-lowpass-plan.json) | Step応答`e^(−t) Σ(k=16…∞) t^k/k!` | −1が16個、数値的に安定 |
| [16Delay](../samples/state-space/sixteen-delays-plan.json) | Ts=0.2秒、3.2秒後にStep取得、`exp(−j16ωTs)` | 0が16個、単位円内 |

モデルサンプルの選択欄にも3モデルを追加しました。解析設定JSONを状態空間画面で読み込むと、離散領域と周期を含む設定を復元できます。解析前後に元モデルの時間応答と履歴を保持します。

全3モデルで16状態・16個の固有値・可制御性／可観測性の数値ランク16を確認しています。16積分器へ単位負帰還を接続した結合モデルでは、特性式`s^16+1`の16根を独立した`exp(j(2k+1)π/16)`と照合します。Routh表で未確定になる場合はその判定を維持し、固有値座標の確認だけで安定性を断定しません。

同じ極を持つ2枝はランク1でも2状態を保持し、極の差が1e−9程度の2枝は閾値付近として表示します。極端な尺度の未解決、入力に無関係な状態、出力ゲイン0、非可観測なPIDフィルタ、17状態の拒否、階層内部・ベクトル成分・320px・中止・保存復元を検証します。詳細と途中の失敗は[検証記録](validation.md)に記載します。

最大16状態の浮動小数点評価であり、重根・近接根・非正規行列・尺度の大きく異なる系の座標精度や厳密な安定性を保証しません。未解決・境界の判定は残し、部分的な固有値を成功結果として返しません。
