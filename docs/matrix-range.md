# 行列応答比較の区間評価

比較が完了したら「比較する区間を指定」を開きます。開始・終了サンプル番号を入力するか、[カーソル](matrix-cursor.md)で選んだ点を開始／終了にします。初回は全区間、両端を含む0〜最終点の整数、開始≦終了です。カーソルは区間の外にも移動でき、出力切替やカーソル移動だけでは区間を変えません。

グラフの青い範囲と境界線が、集計する取得時刻を表します。全出力についてΔ=離散−連続の最大絶対値、RMS、終了点の符号付き差、絶対差積分を表示します。

- 最大差は区間内の実取得点の最大 |Δ|。
- RMSは `sqrt(sum(Δ²)/点数)`。時間で重み付けする指標ではありません。
- 終端差は区間の最後の実取得点のΔ。
- 絶対差積分は隣接する実取得時刻の間隔を使う `sum((|Δ前|+|Δ後|)/2 × Δt)`。サンプル点間の台形近似であり、実際のサンプル間誤差を積分した保証ではありません。時間は秒、積分値の単位は出力値の単位×秒です。

1点だけも選べます。そのとき最大差／RMSはその点の |Δ|、終端差はΔ、絶対差積分は0です。RMSと積分は既存の正規化した集計関数を使い、大きな有限値の二乗だけによるオーバーフローを避けます。差分や指標自体が有限範囲を超える場合は「範囲超過」とし、0で埋めずに区間保存を無効にします。

空欄・小数・範囲外・逆転した両端は、前回の区間・表・グラフを保持してエラーを表示し、区間保存を無効にします。有効な両端の入力、カーソルからの指定、全区間への復帰で修復できます。全結果の保存形式は変えません。

## 区間の保存と実行条件

区間結果JSONの `format` は `blocksim.matrix-comparison-range`、`version` は1です。前回実行した比較条件 `plan` と変換結果 `conversion`、区間の両端・時刻・点数・全出力指標 `range`、元の番号 `sample_indices`、区間だけの実取得時刻・全入力・全連続／離散値を保存します。比較条件ファイルとして読み込む形式ではありません。

区間CSVは元の比較CSVの列を維持し、先頭へ `range_start_sample,range_end_sample,range_sample_index` を追加します。両端を含む区間の全点×全出力を記録し、時刻・入力・行番号・周期番号は元の結果と同じです。step入力にも元のサンプル番号が付きます。番号を0から振り直したり、周期の境界で状態をリセットしたりしません。

区間は表示・集計の指定です。元モデル、履歴、全結果JSON／CSV、比較条件JSONを変更せず、再計算しません。条件を編集しても前回実行済みの値から集計・保存します。有効な入力CSVの遅延読み込みを区間操作によって破棄しません。計算中は前回区間を確認・変更でき、区間保存は完了を待ちます。中止／失敗は前回区間を保持、新しい比較の成功は全区間へ戻ります。正常な比較条件復元やモデル／選択変更で結果が解除されると、区間も解除します。

区間の表示設定を比較条件ファイルへ追加していません。条件の復元と再実行では、同じ結果を全区間から確認できます。最大2001点・全8出力を対象とし、元モデル全体の比較、補間、サンプル間の連続曲線・離散保持の再構成、一般的な誤差／安定性保証は追加しません。[検証記録](validation.md)に実施したチェックを記載します。


[全結果の読み戻し](matrix-result-file.md)は、保存した比較結果JSONを現在のWASMで再計算し、全取得値・変換行列・指標が一致した場合に復元します。区間JSONや条件だけのJSONとは別の操作です。


[作業状態JSON](matrix-session.md)なら、実行済み全結果とカーソル・表示出力・評価区間を一緒に保存し、全結果の再計算一致後に同じ表示へ復元できます。
