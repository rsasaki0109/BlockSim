# サンプルして保持する正弦波の離散化比較

連続TransferFunctionを選び、比較入力を「正弦波をサンプルして保持」にします。周波数Hz、振幅、位相rad、オフセットを設定して「応答を比較」。モデルサンプル「保持正弦波の離散化比較」と[比較設定例](../samples/discrete/sine-comparison-plan.json)も用意しています。

対象は選択した伝達関数を単独・初期状態0で動かすスカラー比較です。元モデルの入力や接続・実行結果は変更しません。入力は`offset + amplitude × sin(2π frequency_hz t + phase_rad)`をTsごとにサンプルして、次のサンプルまで一定に保持します。連続側もこの保持入力を受けます。保持しない連続正弦波と同じ応答という意味ではありません。

実際のDiscrete TransferFunction `[1]/[1]`、初期状態なし、周期Tsを保持ブロックとして使います。両モデルの入力を追加Scopeで記録し、全記録点で一致・有限の1成分・各区間内の保持を確認します。結果に保存する入力は実記録値で、JavaScript側で式から作り直した系列ではありません。比較の時刻・計算予算・中止・実行条件の保持は[保持入力比較の仕様](conversion-comparison.md)と共通です。

## 条件と保存

周波数は0〜Nyquist=`0.5/Ts` Hz。負の周波数・Nyquist超え・非有限値・空欄・未知の設定フィールドを拒否します。振幅は負や0も使えます。0Hzでは位相とオフセットを含む一定値です。Nyquistの位相0では、理論上のサンプル値が0になる場合があるため、正弦波の振幅だけで入力の大きさを判断しないでください。有限精度の微小な残差が出ることがあります。

version 1の任意フィールドは`input: {kind: "sampled_sine", frequency_hz, amplitude, phase_rad, offset}`です。設定読み込みは100 KBまで。同じ元係数の連続ブロックを選んで読み込むと条件を復元し、再実行を待ちます。入力指定なしの旧設定は入力1、`held_step`は従来の1回変更する入力として保持します。

結果JSONは実行時の設定、変換係数、時刻・実入力・連続／離散値・最大差／RMS差などを保存します。正弦波には変更サンプルがないため、変更以後の指標は追加しません。CSVは既存6列に`input,frequency_hz,amplitude,phase_rad,offset`を追加し、全サンプルを出力します。フォームを編集しても、表示・結果JSON・CSVは前回の実行条件のままです。設定ファイルは現在のフォーム条件を保存します。結果JSONの再読み込みは未対応です。

## 独立した数値検証

`source scripts/rust-env.sh`の後、`cargo run --locked --example sine_comparison`で[検証JSON](sine-comparison-validation.json)を再生成できます。全8ケースは101サンプル・単独・初期状態0です。

| 伝達関数・入力 | 方式 | 最大絶対差 | RMS差 |
| --- | --- | ---: | ---: |
| 1/(s+1)²、0.5Hz、Ts=0.2s、振幅1／位相0.4／offset0.25 | ZOH | 1.0973e−12 | 5.8499e−13 |
| 同上 | Tustin | 0.03550696 | 0.01896645 |
| 1/(s+1)²、Nyquist2.5Hz、振幅−0.5／位相π/2／offset0.25 | ZOH | 2.9243e−13 | 2.0832e−13 |
| 同上 | Tustin | 0.009300551 | 0.002802658 |
| 1+1/(s+1)、1.3Hz、Ts=0.1s、直接項あり | ZOH | 2.0689e−13 | 8.6330e−14 |
| 同上 | Tustin | 0.06015156 | 0.03493263 |

`r=exp(−Ts)`として、連続側の独立した保持区間の更新式は、一次で`x[k+1]=r x[k]+(1−r)u[k]`、二段の一次遅れで`x1[k+1]=r x1[k]+(1−r)u[k]`、`x2[k+1]=r x2[k]+Ts r x1[k]+[1−(1+Ts)r]u[k]`です。初期状態は0で、2次出力はx2、直接項付き一次は`u+x1`。ZOHもこのサンプル式と比較します。

Ts=0.2sの2次Tustinは`y[k]=(18/11)y[k−1]−(81/121)y[k−2]+(u[k]+2u[k−1]+u[k−2])/121`、直接項付き一次は`y[k]=u[k]+v[k]`、`v[k]=[(2−Ts)/(2+Ts)]v[k−1]+[Ts/(2+Ts)](u[k]+u[k−1])`と照合します。過去の入力・状態は0です。

全8ケースの独立式との最大誤差は、連続1.098e−12以下、離散1.445e−15以下でした。実入力は両側で全記録点が完全一致し、サンプル間の保持も確認しました。0Hz、Nyquist、負振幅、位相、オフセット、直接項、丸めを含む時計、旧形式／設定復元、誤入力時の結果保持、中止、320px表示をRust・実WASM・GUIで検証します。

この検証は保持入力のサンプル時刻の比較です。任意の入力系列、非ゼロ初期状態、元モデル全体、サンプル間の波形や任意の高次係数の一致を保証しません。Nyquist超えの入力のエイリアシング比較は提供しません。
