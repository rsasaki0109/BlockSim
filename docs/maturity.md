# 成熟度比較コメント

当初の目標は **Simulink 比30%** を維持します。可変刻み計算とパラメータ掃引を加えた現在の概算は **Simulink 比約40%、Scilab/Xcos 比約45%** とします。これは **主観的な開発評価** であり、競合製品の全機能を数えて算出した割合でも、性能・信頼性の客観的なベンチマークでもありません。実務用製品と同じ保証を持つという意味でもありません。

従来の約5%評価は PID 専用実験画面のみの段階でした。これまで、会話で示した30%段階の開発範囲を、次の実装と検証で満たしました。

| 評価する観点 | 今回の根拠 |
|---|---|
| モデル作成 | 任意ブロックの追加・位置変更・接続・削除、閉ループを含むトポロジー実行 |
| モデル規模の整理 | サブシステム化・内部編集・グループ解除・入れ子・複数入出力 |
| 連続／離散の混在 | 結合 RK4 状態と、整数倍の複数離散時計・保持・Delay |
| 信号の扱い | 明示的なベクトル幅、成分ごとの PID / 制限、Mux / Selector |
| 日常的な編集 | コピー／貼り付け・複製、階層を含むブロック検索、モデル診断と問題箇所への移動、自動配置、ズーム・全体表示、未保存変更の保護、Undo / Redo、ポート配線と接続削除、設定欄、作成途中の保存、JSON 復元／追加読み込み、モデル位置保存 |
| 結果の確認 | Scope の複数系列、表示選択、カーソル値、全記録点 CSV、基準結果と設定の保持、波形・数値差分・全対応成分 CSV の比較 |
| 数値の裏付け | 一次遅れ解析解・RK4 刻み半減・Step の厳密な面積・Delay 同期・旧 PID 結果との一致 |
| 再現性 | 固定ツール・lockfile、4サンプル、Rust / 実 WASM / GUI 自動テスト、実行仕様の文書化、実行結果ファイルの保存と再計算による読み込み照合 |

この限定した基本モデリング範囲が一通り使えるため、当初の30%目標に到達した評価を維持します。次の40%段階では、RK45 の誤差制御・記録時計から独立した内部刻み、同期した離散／Step 境界、実際の評価回数統計、独立ケースのパラメータ掃引・IAE／ISE・保存／復元・比較への接続を実装しました。解析解、細かい RK4、旧結果 JSON の完全一致、実 WASM・GUI テストを根拠として、限定した開発評価を40%／45%へ更新します。

今後の対話の末尾にも成熟度を記載します。機能追加だけで機械的に割合を増やさず、未解決の数値・保存・操作上の問題があれば評価を見直します。具体的な未実装項目は [ブロック図仕様](graph.md#現在の範囲) を参照してください。

以前の編集操作の改善だけの段階では、ソルバやライブラリの範囲が増えなかったため約30%／約35%としました。その比較コメントは過去の評価として維持します。PID Lab 単体の当初30%目標は [PID 仕様](pid.md#成熟度比較コメント) に残します。

40%／45%は機能数から算出した値ではありません。剛性・DAE・一般イベント検出、物理領域、周波数応答、コード生成、互換性、業務運用の検証などは依然不足しています。教育・小規模な制御系実験を中心とした評価であり、製品全体の40%の機能や信頼性を証明しません。次に50%を狙う場合はブロックと解析機能の拡充、50〜60%では剛性・イベント処理・規模への対応が必要です。将来の到達率や期限は保証しません。
