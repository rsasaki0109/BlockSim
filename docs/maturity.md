# 成熟度比較コメント

当初の目標は **Simulink 比30%** を維持します。可変刻み・掃引・伝達関数・連続線形の周波数応答に、明示した開ループの余裕解析と、選択した伝達関数の極・零点／内部安定性と、接続された連続線形部分の状態空間・固有値と同一周期の離散状態空間・単位円の安定性と離散Bodeと明示した離散開ループの余裕とDiscrete TransferFunctionとTustinとZOH離散化とSampled Inputを加えた現在の概算は **Simulink 比約64%、Scilab/Xcos 比約69%** とします。これは **主観的な開発評価** であり、競合製品の全機能を数えて算出した割合でも、性能・信頼性の客観的なベンチマークでもありません。実務用製品と同じ保証を持つという意味でもありません。

従来の約5%評価は PID 専用実験画面のみの段階でした。これまで、会話で示した30%段階の開発範囲を、次の実装と検証で満たしました。

| 評価する観点 | 今回の根拠 |
|---|---|
| モデル作成 | 任意ブロックの追加・位置変更・接続・削除、閉ループを含むトポロジー実行 |
| モデル規模の整理 | サブシステム化・内部編集・グループ解除・入れ子・複数入出力 |
| 連続／離散の混在 | 結合 RK4 状態と、整数倍の複数離散時計・保持・Delay |
| 信号の扱い | 明示的なベクトル幅、成分ごとの PID / 制限、Mux / Selector |
| 日常的な編集 | コピー／貼り付け・複製、階層を含むブロック検索、モデル診断と問題箇所への移動、自動配置、ズーム・全体表示、未保存変更の保護、Undo / Redo、ポート配線と接続削除、設定欄、作成途中の保存、JSON 復元／追加読み込み、モデル位置保存 |
| 結果の確認 | Scope の複数系列、表示選択、カーソル値、全記録点 CSV、基準結果と設定の保持、波形・数値差分・全対応成分 CSV の比較 |
| 数値の裏付け | 一次遅れ解析解・RK4 刻み半減・Step の厳密な面積・Delay 同期・旧 PID 結果との一致 |
| 再現性 | 固定ツール・lockfile、4サンプル、Rust / 実 WASM / GUI 自動テスト、実行仕様の文書化、実行結果ファイルの保存と再計算による読み込み照合 |

この限定した基本モデリング範囲が一通り使えるため、当初の30%目標に到達した評価を維持します。次の40%段階では、RK45 の誤差制御・記録時計から独立した内部刻み、同期した離散／Step 境界、実際の評価回数統計、独立ケースのパラメータ掃引・IAE／ISE・保存／復元・比較への接続を実装しました。解析解、細かい RK4、旧結果 JSON の完全一致、実 WASM・GUI テストを根拠として、限定した開発評価を40%／45%へ更新します。

前段では、0〜8次の連続伝達関数・ベクトル独立状態、連続 LTI の Bode／複素応答、選択成分・階層・閉ループ、設定復元・全点 CSV を追加しました。解析解との複素誤差、時間応答と調和応答の照合、特異点・零応答・上限・中止・保存の検証から、線形制御モデルの確認範囲が広がったと判断し、概算を45%／50%へ更新しました。この段階は50%段階に向けた一部で、余裕や離散系解析を含む解析環境の完成とは評価していません。

前段では、開ループを明示して扱うゲイン／位相余裕、複数の交差・奇数倍の位相レベル、複素方程式による絞り込み、未検出・連続一致・欠測・計算予算の区別、GUI・保存／復元・CSVを追加しました。正負の余裕と共振の2交差を独立の解析式と比較し、既存の応答との一致と実 WASM の操作を検証したため、概算を47%／52%へ更新しました。その時点では安定性判定・極零計算・離散系解析が未実装であり、50%段階の解析環境が完成したとは評価していません。

前段では、選択したTransferFunctionと仮定した単位負帰還の極・零点／内部安定性、複素平面、独立したRouth表、境界／近傍・判定不能・求根未解決の区別、保存／復元・全根CSVを追加しました。Cardano式との照合、明示的に作った負帰還伝達関数の減衰・持続振動・増大、相殺された不安定極を保持する検証を根拠に、教育・小規模な連続線形制御実験の限定した範囲で50%／55%と評価します。ブロック図全体の固有値解析や安定性、Nyquist、離散系解析まで完成した意味ではありません。数値結果と判定対象の限界は [極・零点仕様](pole-zero.md) に記載します。

前段では、選択Scope成分の祖先の現在の接続から A・B・C・D を抽出し、最大8状態の固有値・Routh判定・行列残差、保存／復元・CSV／結果JSONを追加しました。PIDの非可観測状態や相殺された不安定状態を残し、201点の独立した状態空間周波数応答との照合、実際に接続された負帰還の100秒の時間応答と解析解との一致を根拠に、限定した開発評価を53%／58%へ更新します。対象はScopeの祖先だけで、モデル全体、MIMO、9状態以上、離散系には広げていません。[状態空間仕様](state-space.md) に数値検証と限界を記載します。

前段では、同一周期のDelay・無制限離散PIDを現在の接続のままサンプル時刻のA・B・C・Dへ抽出し、単位円の極・双一次変換と独立Routh判定、周期と解析領域の保存／復元を追加しました。実PID／同期Delayとの時間応答一致、既知の複素極と有限等比級数の独立Step式、境界・未解決・混在周期の拒否、実WASM／GUI検証を根拠に、限定した主観的な開発評価を55%／60%へ更新します。離散Bode・混在系・全モデルの解析は含みません。[離散仕様](discrete-state-space.md) に数値と限界を記載します。

前段では、同一周期の離散状態空間から単位円上のBode応答、周期／Nyquist上限／rad/sampleの明示、領域の保存／復元、全点CSVを追加しました。離散PIDの更新式・2段Delayの独立解析式、実正弦波応答、Nyquistの特異点・零応答・GUI保持の検証を根拠に、限定した主観的な開発評価を57%／62%へ更新します。離散余裕・異なる周期・連続プラントとの混在解析は含みません。[離散Bode仕様](discrete-frequency.md) に数値と限界を記載します。

前段では、同一周期の離散開ループのゲイン／位相余裕、Nyquist内の複数交差・端点、周期付き全候補CSV・復元を追加しました。独立した交差式と正／ほぼゼロ／負の余裕、明示的に接続した閉ループの極・Step応答、正の余裕でも不安定となる反例、実WASM／GUI検証を根拠に、限定した主観的な開発評価を59%／64%へ更新します。一般的な安定性証明、最も厳しい余裕の自動選択、異なる周期や連続プラントとの混在解析は含みません。[離散余裕仕様](discrete-margins.md) に数値と限界を記載します。

前段では、連続伝達関数のTustin係数変換、任意のプリワープ、GUIでの係数確認・適用・Undoと保存／復元を追加しました。独立した1〜8次の複素式、極の写像、実Stepとプリワープの実Bode、非ゼロ初期状態／直接循環／数値未解決の拒否を根拠に、限定した主観的な開発評価を62%／67%へ更新します。ZOHや非ゼロ初期状態の写像、一括変換、汎用の安定性証明を含むものではありません。[変換仕様](tustin.md) に数値と限界を記載します。

今後の対話の末尾にも成熟度を記載します。機能追加だけで機械的に割合を増やさず、未解決の数値・保存・操作上の問題があれば評価を見直します。具体的な未実装項目は [ブロック図仕様](graph.md#現在の範囲) を参照してください。

以前の編集操作の改善だけの段階では、ソルバやライブラリの範囲が増えなかったため約30%／約35%としました。その比較コメントは過去の評価として維持します。PID Lab 単体の当初30%目標は [PID 仕様](pid.md#成熟度比較コメント) に残します。

64%／69%は機能数から算出した値ではありません。剛性・DAE・一般イベント検出、物理領域、異なる周期・連続／離散混在の周波数応答、多ブロック図全体の安定性・余裕の網羅性、コード生成、互換性、業務運用の検証などは依然不足しています。教育・小規模な制御系実験を中心とした評価であり、製品全体の64%の機能や信頼性を証明しません。次へ進むには、より多くの状態・モデル全体の解析、交差の網羅性・Nyquist判別・混在系の解析に加え、剛性・イベント処理・規模への対応が必要です。将来の到達率や期限は保証しません。
