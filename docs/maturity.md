# 成熟度比較コメント

目標は **Simulink 比30%** を維持します。現在の概算は **Simulink 比約30%、Scilab/Xcos 比約35%** とします。これは **主観的な開発評価** であり、競合製品の全機能を数えて算出した割合でも、性能・信頼性の客観的なベンチマークでもありません。実務用製品と同じ保証を持つという意味でもありません。

従来の約5%評価は PID 専用実験画面のみの段階でした。今回、会話で示した30%段階の開発範囲を、次の実装と検証で満たしました。

| 評価する観点 | 今回の根拠 |
|---|---|
| モデル作成 | 任意ブロックの追加・位置変更・接続・削除、閉ループを含むトポロジー実行 |
| モデル規模の整理 | サブシステム化・内部編集・グループ解除・入れ子・複数入出力 |
| 連続／離散の混在 | 結合 RK4 状態と、整数倍の複数離散時計・保持・Delay |
| 信号の扱い | 明示的なベクトル幅、成分ごとの PID / 制限、Mux / Selector |
| 日常的な編集 | コピー／貼り付け・複製、階層を含むブロック検索、自動配置、ズーム・全体表示、未保存変更の保護、Undo / Redo、ポート配線と接続削除、設定欄、作成途中の保存、JSON 復元／追加読み込み、モデル位置保存 |
| 結果の確認 | Scope の複数系列、表示選択、カーソル値、全記録点 CSV |
| 数値の裏付け | 一次遅れ解析解・RK4 刻み半減・Step の厳密な面積・Delay 同期・旧 PID 結果との一致 |
| 再現性 | 固定ツール・lockfile、4サンプル、Rust / 実 WASM / GUI 自動テスト、実行仕様の文書化 |

この限定した基本モデリング範囲が一通り使えるため、会話内で定めた30%段階に到達したと判断します。未実装の高度なソルバ、物理領域、コード生成、互換性、業務運用の検証などの大きさを考慮し、これ以上の割合や製品同等性は主張しません。

今後の対話の末尾にも成熟度を記載します。機能追加だけで機械的に割合を増やさず、未解決の数値・保存・操作上の問題があれば評価を見直します。具体的な未実装項目は [ブロック図仕様](graph.md#現在の範囲) を参照してください。

今回の編集操作の改善は、既存のモデリング機能を使いやすくする変更です。ソルバやライブラリの範囲が増えたわけではないため、概算は約30%／約35%のままとします。
