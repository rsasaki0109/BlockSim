# 離散伝達関数ブロック

ブロック種類「Discrete TransferFunction」は、同じ係数を各ベクトル成分へ独立に適用する離散線形フィルターです。GUIで分子・分母・companion初期状態・周期を設定し、通常のモデルJSON、ブラウザ保存、階層化・コピー、実行結果ファイルへ保存できます。モデルversion1／保存文書version2は維持します。

## 係数と初期状態

`kind:"discrete_transfer_function"`、`numerator`、`denominator`、`initial`、`sample_time` を指定します。係数は **zの降べき順**。分子・分母は空でない有限数値配列、分子次数≤分母次数≤8、分母の先頭は0以外です。短い分子は高次側へ0を補います。z⁻¹の定数項側から書くDSP係数とは、短い配列の意味が異なります。

| 分子／分母 | G(z) | 単位Stepのサンプルnでの出力（初期状態0） |
|---|---|---|
| `[0.2,0]`／`[1,-0.8]` | 0.2z/(z−0.8) = 0.2/(1−0.8z⁻¹) | 1−0.8^(n+1)、初回0.2 |
| `[0.2]`／`[1,-0.8]` | 0.2/(z−0.8) | 1−0.8^n、初回0 |
| `[0.25,0.5,0.25]`／`[1,0,0]` | 0.25+0.5z⁻¹+0.25z⁻² | 0.25、0.75、1、… |
| `[1]`／`[1,0]` | z⁻¹ | Unit Delayと同じ（初期出力は状態値） |
| `[6]`／`[2]` | 3 | サンプル時刻で入力×3を取得して保持 |

分母の先頭で正規化した `1,a1,…,an`、高次側を補った分子 `b0,b1,…,bn` に対し、各成分の状態は以下です。連続伝達関数と同じcompanion配置を、微分でなく次のサンプル状態として使います。

```text
y[k]    = b0 u[k] + Σ (bj − aj b0) xj[k]
x1[k+1] = u[k] − Σ aj xj[k]
xj[k+1] = x(j−1)[k]       (j=2,…,n)
```

`initial` は成分ごとにn個を並べ、長さは信号幅×n。過去出力の配列ではなく上式の内部状態です。次数0なら空配列。正規化係数・出力係数が非有限になる場合は事前拒否し、実行時の状態／出力オーバーフローもエラーにします。極零相殺や状態削除は行いません。

## 時計と同期

周期は正の有限値で、記録刻みdtの整数倍。t=0から周期ごとに `y[k]=Cx[k]+Du[k]` を計算して出力を保持します。サンプル間に入力が変わっても直ちには反映せず、次のサンプルで取得します。

全Delay／離散伝達関数の前回採取した状態をコミットしてからブロック出力を評価し、評価済みの同じ信号から次の状態を採取します。次状態をその場で隣のブロックへ渡さないため、ブロック配列を並べ替えても同期を維持します。次数0も周期付きの取得・保持です。

現在の入力を使うb0≠0は直接伝達。閉じた直接伝達循環は既存の代数ループ診断で拒否します。b0=0かつ次数≥1は状態のみで出力でき、帰還を切れます。サンプル時刻の後にPIDが更新した信号も、評価順に従って下流へ渡し、次状態は全出力の評価完了後に採取します。

RK4／RK45の両方に対応。離散状態は連続積分の状態から分離し、RK45の内部段階・棄却・再試行で更新しません。RK45はサンプル境界で積分区間を分けます。異なる整数倍の周期、連続プラントとの混在は時間シミュレーションで扱えます。

## 解析と数値検証

選択Scope祖先の **同一周期・最大8状態** の離散状態空間・Bode・明示した開ループの余裕へ対応します。実際の出力／次状態式を単位状態・単位入力で評価し、周期付きA・B・C・Dを抽出します。次数0でも離散周期を保持。他の関連する離散ブロックと周期が異なる場合、連続状態が関連する場合は解析前に拒否します。連続領域や単一の連続TransferFunction用の極零パネルでは扱いません。

相殺した `G(z)=(z−1.1)/(z−1.1)` でも内部の単位円外状態を残し、内部安定性は不安定と判定します。8次のz⁻⁸も8状態を残し、関連状態が9個なら拒否。Bodeの特異点・零応答、位相枝・有限帯域の余裕の限界は既存の[離散状態空間](discrete-state-space.md)・[離散Bode](discrete-frequency.md)・[離散余裕](discrete-margins.md)と同じです。

[transfer.json](../samples/discrete/transfer.json) またはサンプル「離散伝達関数：直接項と1サンプル遅れ」で、Ts=0.1s・dt=0.02sの2つの低域フィルターを比較します。[transfer-plan.json](../samples/discrete/transfer-plan.json) で離散Bodeの領域・範囲も復元できます。

`cargo run --locked -p blocksim-core --example discrete_transfer` は直接IIR／遅れIIR／FIRの5秒・251記録点を独立したStep式と照合し、201複素点を独立の単位円式と比較します。さらに実Sine駆動シミュレーターの24〜40秒、160サンプル時刻・20周期をsin／cosへ投影し、Bodeと照合。[数値JSON](discrete-transfer-validation.json) の最大Step誤差は5.56e−16未満、複素誤差4.75e−16未満、実時間の調和応答との誤差6.05e−15未満です。選んだモデル・有限窓の検証で、一般の誤差保証ではありません。

連続伝達関数からの自動離散化、z⁻¹形式の別入力、最小実現、汎用Nyquist判別、異なる周期のlifting／混在系の周波数解析、MIMO・9状態以上の解析は未実装です。
