# 伝達関数と周波数応答

ブロック図エディタで連続の線形モデルの Bode 線図を求められます。同じモデルを RK4／RK45 で時間応答として実行でき、モデルや時間応答の結果・履歴を変更せずに周波数応答を解析します。PID Lab の計算方式は維持します。

## TransferFunction ブロック

`TransferFunction` は実係数の連続伝達関数です。分子・分母を `s` の降べき順で指定します。分母の先頭は0以外、係数は有限値、分子次数は分母次数以下、分母次数は0〜8です。次数0は定数ゲインです。信号幅を増やすと、同じ係数の独立したフィルターを各成分へ適用します。

```json
{
  "kind": "transfer_function",
  "numerator": [1],
  "denominator": [1, 2, 1],
  "initial": [0, 0]
}
```

これは `G(s)=1/(s+1)²` です。`initial` は各信号成分につき分母次数個、成分ごとに並べた状態です。2成分なら `[0,0,0,0]`、次数0なら `[]`。係数・状態・幅は既存のモデル JSON／ブラウザ保存に含み、編集・コピー・階層化・Undo／Redo、掃引でも扱えます。分子・分母の次数を変えるときは状態数も合わせてください。

分母を先頭係数で正規化して `[1,a₁,…,aₙ]`、分子を左にゼロで埋めて同じ長さの `[b₀,b₁,…,bₙ]` とすると、状態は次の実現です。

```text
x₀' = u − a₁x₀ − … − aₙxₙ₋₁
x₁' = x₀, …, xₙ₋₁' = xₙ₋₂
y = b₀u + Σᵢ₌₁ⁿ (bᵢ − aᵢb₀)xᵢ₋₁
```

非ゼロ初期値はこの状態変数の値で、出力の初期値そのものではありません。厳密にプロパーな場合は状態から出力し、フィードバックの代数ループを切れます。`b₀≠0` の直接伝達を持つループは従来どおり拒否します。係数の正規化が有限値で表せない場合は実行前に拒否します。

RK45 は全連続状態と結合して積分します。RK4 は固定刻みです。任意の伝達関数の安定性や適切な刻みは保証せず、特に速い極を持つモデルでは可変刻みと許容誤差を検討してください。極零相殺・最小実現や剛性ソルバは行いません。

## 解析の操作

1. モデルサンプル「伝達関数：2次ローパス」「線形 PI 閉ループ」または「開ループのゲイン／位相余裕」を読み込みます。独自の線形モデルも解析できます。
2. 「周波数応答 / Bode」を開き、信号源と入力成分、Scope と出力成分を選びます。番号は0から。階層内の同じ ID は完全なパスで区別します。
3. 最小／最大角周波数を **rad/s** で指定し、対数間隔の点数を選びます。Sine ブロックの設定単位 Hz とは異なり、`ω=2πf` です。
4. 「周波数応答を解析」で振幅・位相を表示し、解析点カーソルで複素応答を確認します。「全解析点」は50件ずつ表示します。
5. 「周波数応答 CSV」で全解析点、信号源／Scope／成分、実部・虚部・振幅・dB・位相・残差・エラーを保存します。失敗点や零応答を除外せず記録します。

入力は選択した Constant／Step／Sine の1成分へ加える単位の変動です。他の成分・信号源の変動はゼロとし、初期状態や信号源の実際の振幅・オフセット・Step 時刻／Sine 周波数は周波数応答に使いません。絶対値の時間波形や非線形モデルの動作点における線形化ではありません。

対象 Scope へ影響する成分だけをたどるため、大きな独立ベクトルの他成分を不要に行列へ含めません。モデル全体は通常の実行前検証を通る必要があります。時間応答を実行せずに解析しますが、既存の時計・記録予算・RK4 の条件チェックは維持します。許可された同一モデルの周波数計算値は時間刻み／ソルバに依存しません。

## 対応範囲

| ブロック | 周波数応答での扱い |
|---|---|
| Gain、Sum | 線形係数、分岐・閉ループを含む |
| FirstOrder、Integrator | `gain/(1+τs)`、`1/s` |
| TransferFunction | 指定した分子／分母を `s=jω` で評価 |
| 連続 PID | 制限のない `kp + ki/s + kd·s/(1+derivative_tau·s)` |
| Mux、Selector、Input／Output、Scope | 対応するベクトル成分・境界接続 |
| 制限なし Saturation、入力1個の Product | 恒等伝達 |

選択 Scope の関連範囲に出力制限付き PID／Saturation、複数入力 Product、離散 PID／Delay がある場合は対象外として拒否し、ブロックの正確な ID を示します。無関係な枝の非線形ブロックは応答に含めません。anti-windup は制限がない場合だけ許容し、線形化の代用に無効化しません。サブシステム・ベクトル成分・連続状態で切ったフィードバックにも対応します。

## 計算法と失敗点

伝達関数の係数は分母の先頭で正規化してから周波数多項式を評価し、等価な大きい係数のスケールによる不要なオーバーフローを避けます。

各角周波数で、関連する信号成分の `y = F(jω)y + u` を複素行列として構成し、行をスケーリングして部分ピボット付き消去で解きます。正規化後のピボットが `1e-12` 未満なら特異／悪条件として拒否し、正規化残差が `1e-10` を超える解も採用しません。極や数値範囲外の点はエラーとして返し、グラフをその点の前後で結びません。行列の条件によって、数学的に有限の応答も拒否する場合があります。

零応答は振幅0、dBは−∞、位相未定義です。JSON／CSV の dB・位相欄は `null`／空欄にし、状態を `zero` とします。特異点は数値を `null`／空欄にし、`error` と理由を記録します。`null` を0として描画しません。全点が失敗した場合はエラー表示し、有効点数を偽りません。

位相は `atan2` から求め、隣り合う有効点の差が最も小さくなるよう360度の折り返しを補正します。零応答・失敗点で接続を切り、その後は補正を再開します。粗い点数では位相回転を取り逃すため、必要に応じて点数を増やしてください。

角周波数は `1e-9 ≤ 最小 < 最大 ≤ 1e9`、点数は2〜2048、関連成分の変数は最大128。`(点数 + 余裕の追加評価回数) × 変数数³ ≤ 2000万` とします。余裕解析の追加評価は、この残り予算内で最大4096回です。この予算チェックは WASM の32ビット整数でもオーバーフローしない形で行います。極端に狭い範囲は浮動小数点で記録点／対数軸を区別できないため、対数刻みが `64 × machine epsilon` 以下なら拒否します。

これは連続 LTI の形式的な伝達特性です。Bode 線図が計算できても、安定な定常応答、閉ループ安定性、ゲイン／位相余裕やチューニングの適切さを保証しません。離散／混在周波数応答、一般の線形化、ブロック図全体の極零計算・相殺、モデル全体の安定性の判定は未実装です。選択したTransferFunctionと仮定した単位負帰還の極・零点／内部安定性は [極・零点仕様](pole-zero.md) で扱います。開ループ余裕は次の限定した方式で扱います。

## 開ループのゲイン／位相余裕

「選択した伝達を開ループ L(s) として余裕を解析」を有効にしたときだけ計算します。**単位負帰還 `T(s)=L(s)/(1+L(s))` を想定**し、選んだ信号源→Scope が実際に開ループの伝達であることを利用者が指定します。既存の接続を自動で切断したり、閉ループ応答 T(s) を L(s) に変換したりしません。通常の閉ループ Bode を、そのままループ伝達の余裕として解釈しないでください。未指定の既存設定は応答解析のみです。

- **ゲイン交差**：振幅0 dBの候補ごとに、角周波数・展開した位相・`PM=180°+位相` を表示します。位相は最初の有効点の atan2（−180〜180度）から標本で展開し、零応答・欠測で再開します。±180度への正規化や、複数の巻き数からの「最も危険な」余裕の選択は行いません。PMの数値はこの位相の枝を参照し、位相が−540度のときは−360度になります。狭い周波数範囲・粗い標本・欠測で枝が変わり得るため、位相欄と範囲も確認してください。
- **位相交差**：展開した位相が `−180°+360°k` を通る各候補に、角周波数・その位相レベル・`GM(dB)=−振幅(dB)`・倍率 `10^(GM/20)` を表示します。倍率が有限の正数で表せない場合だけ `null`／空欄／「範囲外」とし、dB値は保持します。
- 標本間の符号変化から区間を探し、対数周波数の二分法で**元の複素方程式を再評価**します。最大48回、閾値の残差1e−10 dB／度以内で確定します。対数区間が1e−12より狭くなっても閾値へ収束しない場合は未解決です。補間だけで余裕を確定しません。
- 格子上の閾値一致（0 dBは1e−10 dB以内、位相レベルは1e−8度以内）は重複を除いて保持し、指定範囲の端点も含めます。有効点が欠測に挟まれて孤立している場合は交差としません。隣接標本が両方閾値へ一致する区間は、孤立した交差を特定できないため、端点も交差として返さず「連続一致」と表示します。これは標本間全体の数学的な恒等性を証明するものではありません。
- 零応答・計算不能な点をまたいで交差を推測しません。隣接位相差が180度付近では枝の選択が曖昧なため、その区間を飛ばして点数の増加を案内します。追加計算予算・収束・複素方程式の問題も未解決の区間と理由を表示します。

すべての候補を周波数順に表示し、Bode 図に交差点を示します。**未検出は「指定範囲の標本間で未検出」であり、無限大の余裕ではありません。** 同じ区間内で偶数回交差する狭い共振や、標本に載らない接触は検出できないことがあります。例えば共振モデル `0.2/(s²+0.1s+1)` は0.1〜10 rad/sを2点だけで見ると交差を取り逃し、201点では2つ検出します。

正の余裕でも安定性を証明しません。例えば不安定な開ループ `2/(s−1)` はこの定義でPMが約60度になります。この余裕解析は開ループ極・Nyquist の巻き数・隠れたモード・極零相殺を検査せず、閉ループ安定性を自動判定しません。別の極・零点パネルは選択したTransferFunctionの内部実現だけを判定します。PMとGMからチューニングの適切さを保証しません。

「余裕解析 CSV」は**実行済みの結果**の全候補・未解決区間・未検出を、信号源／Scope／成分・周波数範囲・残差・解釈の注記とともに保存します。解析条件を編集しても既存の結果・CSVは再解析まで保持し、現在のフォーム値で過去の結果を上書きしません。モデル変更／Undoは結果を無効にします。通常の全点 Bode CSV の形式は維持します。

### 再現サンプル

[open-loop-plan.json](../samples/frequency/open-loop-plan.json) を専用欄で読み込むと、開ループの指定も復元します。モデルサンプルから読み込む場合は、チェックを明示的に有効にしてください。

`L(s)=4/[s(s+1)(s+2)]` では `|L(jω)|²=16/[ω²(ω²+1)(ω²+4)]`、位相交差は `ω=√2`、GM倍率は1.5です。独立の解析式で検証します。

| 開ループ | ゲイン交差 (rad/s) | PM (°) | 位相交差 (rad/s) | GM (dB) | GM倍率 |
|---|---:|---:|---:|---:|---:|
| 4/[s(s+1)(s+2)] | 1.143203044 | 11.424981845 | 1.414213562 | 3.521825181 | 1.5 |
| 8/[s(s+1)(s+2)] | 1.625959258 | −7.517996078 | 1.414213562 | −2.498774732 | 0.75 |

分子を4→8に変更すると両余裕が負へ変わります。共振の2交差も含む `cargo run --locked -p blocksim-core --example margins` の数値を [margins-validation.json](margins-validation.json) に保存しました。これらの3ケースでは周波数誤差4.05e−12 rad/s未満、余裕誤差1.88e−10 dB／度未満です。任意のモデルでの精度や交差の網羅性を保証する値ではありません。

## 保存・中止

「解析設定を保存」は現在のモデルと解析条件（任意の `request.open_loop: true/false` を含む）を version 1の `blocksim.frequency` JSON に保存します。`open_loop` が省略された旧ファイルは無効として復元し、数値や文字列は真偽値とみなしません。専用欄で1 MBまで読み込め、通常の未保存確認を経てモデルと条件を復元します。読み込み後は明示的に解析します。結果はタブ内のメモリーで、ページ再読み込みで消えます。設定は通常のモデル JSON に未知のフィールドとして加えず、専用ファイルで保持します。

解析は専用 Worker で行い、通常実行・結果ファイル読み込み・掃引とは同時に開始しません。「解析を中止」で終了し、古い返答は無視します。モデル編集／Undo／置き換えは解析を中止し、以前の解析結果を無効化します。表示・選択・保存・解析自体はモデルや時間応答を変更しません。不正な解析条件／設定ファイルは以前の有効な解析とモデルを保持し、遅れたファイルの読み込みは新しい解析やモデル編集に反映しません。

## 数値検証

```bash
source scripts/rust-env.sh
cargo run --locked -p blocksim-core --example frequency
```

| サンプル | 解析式 | 最大複素誤差（201点） | 時間応答最大誤差（1001点） |
|---|---|---:|---:|
| `lowpass` | `1/(s+1)²` | 2.49e−16未満 | 5.04e−10未満 |
| `feedback` | `(2s+1)/(s²+3s+1)` | 2.71e−16未満 | 3.18e−10未満 |

前者の単位 Step は `1−(1+t)e⁻ᵗ`、後者は2つの実極による解析解と比較します。別の調和入力試験では、40秒以降の時間応答と `Re(G)sin(t)+Im(G)cos(t)` が `5e-8` 以内で一致しました。次数3の位相折り返し、全 PID 項、非ゼロ初期値・非モニック係数・直接伝達・次数0・ベクトル独立性、階層／Mux／Selector、特異点・零応答・各上限も検証しています。

詳細は [frequency-validation.json](frequency-validation.json)。これは2つのサンプルでの精度であり、任意のモデルで同じ誤差を保証しません。設定を再現する [lowpass-plan.json](../samples/frequency/lowpass-plan.json)、[feedback-plan.json](../samples/frequency/feedback-plan.json) は GUI の「解析設定を読み込む」で使えます。

現在の接続から選択Scope成分の祖先のA・B・C・Dと固有値を求める解析は [状態空間仕様](state-space.md) を参照してください。最大8状態の内部実現に限り、Bodeパネルの意味や開ループ余裕の判定範囲は変えません。
