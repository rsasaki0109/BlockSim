# 行列離散化の保持入力比較

連続StateSpaceの設定欄でZOH／Tustin・周期・プリワープを選び、その下の「行列の保持入力応答比較」から実行します。入力は変更前／後のJSONベクトル、変更サンプル、比較点数を指定。入力の幅はDの列数m、出力はCの行数pです。初回はサンプル0、変更位置は1〜点数−1。2〜2001点、入力／出力各1〜8、状態0〜16に対応します。

比較は**選択した行列だけを単独で実行**します。元モデルの接続、入力、記録時計、ソルバや完了したScope結果は使わず、変更しません。上の未適用の行列編集も使いません。行列変換を元モデルへ適用する操作とは別です。連続モデルをRK45で、変換後を離散出力保持で実行し、両方の実入力も記録します。初期値はZOHではそのまま、Tustinでは0のみ。詳しい変換式は[行列離散化](matrix-discretization.md)を参照してください。

記録刻みはTs/10、終端は(点数−1)Ts。RK45はabs/rel tolerance=1e−11、max_step=Ts/10、min_step=max(Number.MIN_VALUE,Ts×1e−12)。同じサンプル時刻で1回だけ入力を変え、サンプル間は両モデルとも保持入力です。実入力が全記録点で一致し、設定した系列と一致することを確かめてからTsごとの出力を取り出します。記録時計・Scope数・全値の幅と有限性を検査し、途中の点や成分だけを成功として表示しません。

各出力についてΔ=離散−連続の最大絶対差、RMS、入力変更以後の同じ指標を表示します。出力を切り替えて、実線の離散／破線の連続を確認できます。線はサンプル点を結ぶ表示で、サンプル間の連続曲線や離散保持を再構成した表示ではありません。ZOHはこの保持入力のサンプル時刻に一致する数値検証です。Tustinでは直接項・周波数写像による時間応答の差があり、プリワープは全時間波形の一致を意味しません。

## 保存・復元と結果の保持

「比較設定 JSON」は `blocksim.matrix-comparison` version1、100 KB上限。元のA・B・C・D／initial・方式・Ts・任意プリワープと、点数・入力ベクトル・変更位置を保存します。[サンプル](../samples/matrix/comparison-plan.json)は非ゼロ初期状態[0.5,−0.25]、ZOH、Ts=0.1、21点、入力[1,2]→[0.25,−1]を変更サンプル12（1.2秒）で切り替えます。GUIモデル「行列のZOH／Tustin離散化」を読み、初期状態を同じ値へ適用してから比較設定を読み込めます。

読み戻しは、選択行列と初期状態が保存時の元設定と同じ場合に条件だけを復元します。モデルを置き換えたり変換を適用したりせず、比較は再実行します。JSONキーの順序は一致判定へ影響しません。未知／不足／null・不正寸法・幅・周期・プリワープ・点数を拒否します。読み込み中にモデル／選択／条件／実行状態が変われば、遅れた読み込みを破棄します。

「比較結果 JSON」は別形式 `blocksim.matrix-comparison-result` version1で、実行した設定、変換行列と残差、全サンプル時刻・実入力・全出力・全差分指標を保存します。設定読み込みには使いません。「比較 CSV」は全点×全出力の行、方式・Ts・プリワープ・変更位置・時刻・出力成分・連続／離散値・Δと引用した入力JSONを含みます。表や条件の編集・出力表示の切り替えで、前回結果やその書き出しを新条件へ付け替えません。実行時の条件を表示に残します。

## 中止・予算・対応範囲

専用Workerで実行し、元モデルの実行・掃引・解析・ファイル検証・変換と排他にします。中止やモデル編集／選択変更はWorkerを終了し、古い応答を無視。失敗・中止は前回の完了比較を保持し、モデル変更／設定の正常復元／設定欄の再作成は比較表示を解除します。関連ボタンが無効な間の合成クリックも拒否します。

各モデルの実計算は1000万block-component evaluations以内、合計最大2000万。既存のブロック・接続・記録予算も適用します。大きな行列や厳しい応答では2〜2001の形式上の点数内でも予算を超え、部分結果を表示せず明示的に失敗します。8入出力・2001点の0状態静的系では全値とCSV 16008行を確認、密な16状態の長い比較では1000万の実計算制限と前回結果の保持を確認します。

元モデル全体、非均一時刻、一般の非ゼロTustin状態写像、サンプルの間に変わる入力、任意入力列／正弦波・混在周期を今回の比較へ追加するものではありません。局所許容誤差や変換残差は一般の誤差・安定性の保証ではありません。独立式・実施したテストは[検証記録](validation.md)に記載します。
