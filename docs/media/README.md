# README の実画面デモ

37本の GIF は、実際の BlockSim GUI と生成済み WASM を Chromium で動かして録画したものです。アプリケーションのソース、モデル計算、結果を録画用に置き換えていません。見やすいレイアウト、見出し、操作位置のマーカー、既存波形の線を描く演出だけを録画時の DOM / CSS に加えています。

波形の線を描く演出は計算結果の紹介用であり、アプリのリアルタイムシミュレーション再生を意味しません。実際のカーソル操作は記録点の値を表示します。機能と数値は [仕様](../graph.md) と [検証記録](../validation.md) を参照してください。

## 再生成

Chromium、ffmpeg（palettegen / paletteuse）、インストール済みの `web/node_modules` と生成済み WASM が必要です。依存パッケージは追加していません。

```bash
cd /workspace/BlockSim
./scripts/build-wasm.sh
node web/scripts/record-demos.mjs
# 1本だけの更新も可能です（対象クリップの manifest 情報も更新）。
node web/scripts/record-demos.mjs anti-windup
```

スクリプトは録画専用 Vite を `127.0.0.1:5180` で起動・終了します。ポートが使用中なら失敗し、他のサーバーを終了しません。`CHROMIUM_PATH` でブラウザのパスを指定できます。クラウドのサンドボックスでローカル待ち受けが EPERM になる場合は、サポートされた実行権限を利用してください。

録画は1120×860、GIF は960×737、10 fps、128色、無限ループです。PNG フレームは一時ディレクトリに置き、GIF 化後に削除します。終端のポスターは目視確認用に一時ディレクトリへ残します。生成スクリプトはブラウザエラー・実行結果・出力サイズをチェックして失敗時に終了します。

各 GIF のフレーム数・時間・ファイルサイズは [manifest.json](manifest.json) に保存しています。1本4 MB未満を上限とし、差分フレームとパレットで軽量化しています。
