# README の実画面デモ

13本の GIF は、実際の BlockSim GUI と生成済み WASM を Chromium で動かして録画したものです。アプリケーションのソース、モデル計算、結果を録画用に置き換えていません。見やすいレイアウト、見出し、操作位置のマーカー、既存波形の線を描く演出だけを録画時の DOM / CSS に加えています。

波形の線を描く演出は計算結果の紹介用であり、アプリのリアルタイムシミュレーション再生を意味しません。実際のカーソル操作は記録点の値を表示します。機能と数値は [仕様](../graph.md) と [検証記録](../validation.md) を参照してください。

## 再生成

Chromium、ffmpeg（palettegen / paletteuse）、インストール済みの `web/node_modules` と生成済み WASM が必要です。依存パッケージは追加していません。

```bash
cd /workspace/BlockSim
./scripts/build-wasm.sh
node web/scripts/record-demos.mjs
# 1本だけの更新も可能です（対象クリップの manifest 情報も更新）。
node web/scripts/record-demos.mjs anti-windup
```

スクリプトは録画専用 Vite を `127.0.0.1:5180` で起動・終了します。ポートが使用中なら失敗し、他のサーバーを終了しません。`CHROMIUM_PATH` でブラウザのパスを指定できます。クラウドのサンドボックスでローカル待ち受けが EPERM になる場合は、サポートされた実行権限を利用してください。

録画は1120×860、GIF は960×737、10 fps、128色、無限ループです。PNG フレームは一時ディレクトリに置き、GIF 化後に削除します。終端のポスターは目視確認用に一時ディレクトリへ残します。生成スクリプトはブラウザエラー・実行結果・出力サイズをチェックして失敗時に終了します。

各 GIF のフレーム数・時間・ファイルサイズは [manifest.json](manifest.json) に保存しています。1本4 MB未満を上限とし、差分フレームとパレットで軽量化しています。

`workspace.gif` は内部設定・接続を含むモデルのコピー／貼り付け、位置の設定、全体表示、実行、保存を録画します。元モデルとコピーの全記録点の一致も生成時に確認します。録画中の置き換え確認はスクリプトが承諾し、撮影用モデルの変更を進めます。

`layout.gif` は重なった複製モデルの自動配置・Undo／Redo・実行・保存を録画します。配置前後の時刻・全 Scope の全記録値が完全一致することを生成時に確認します。

`search.gif` は同じローカル ID を持つ内部 Gain を階層パスで区別し、コピー側の設定だけを変更する操作を録画します。元の出力3・コピーの出力5と未保存判定を実 WASM・GUI で確認します。検索パネルを表示し、キャンバスと波形の高さを撮影用に縮めています。

`diagnostics.gif` は未接続の Scope 入力を診断し、入力ポートへ移動して配線を直す操作を録画します。問題1件→問題なし、実 WASM の出力6、保存後の未保存判定を確認します。診断パネルを表示し、キャンバスと波形の高さを縮め、1ページだけの場面でページ送りを隠しています。他のクリップでは診断パネルを撮影用に隠します。

`comparison.gif` は内部 Gain が3の結果を基準として保持し、5へ変更して再実行します。t=0.5秒の基準3・現行5・差2、最大絶対差2、重ね表示の切り替えと保存を実 GUI で確認します。比較操作と表を表示し、キャンバス・波形を縮め、基準モデルの書き出しボタンと1ページの送り操作を隠しています。基準の破線を維持するため、描画演出は現行の実線だけに適用します。他のクリップでは比較操作を撮影用に隠します。

`archive.gif` はゲイン3の実行結果を実際にダウンロードし、ゲイン5へ変更後、その保存ファイルを読み込みます。201記録点の再計算との一致、基準3・現行5・差2、最大差2、現行モデルの保存を確認します。ファイル操作欄を開き、キャンバスと波形を縮めて撮影します。他のクリップではファイル操作欄を撮影用に隠します。
