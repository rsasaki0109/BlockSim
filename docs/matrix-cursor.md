# 行列応答比較のサンプルカーソル

行列の比較が完了すると、グラフの下からサンプルを選択できます。スライダー、番号入力、前／次の点、グラフのクリック、グラフにフォーカスした左右キー・Home／Endに対応します。初回の番号は0、新しい比較の完了時はサンプル0へ戻ります。出力成分の切り替えではサンプル番号を保持します。

選んだ点の実取得時刻、全入力成分、選択出力の連続値・離散値・Δ=離散−連続を表示します。表示は実行済みの比較結果から読み、数値を丸めたり再計算したモデルの値へ置き換えたりしません。グラフには時刻の縦線と、連続／離散の実取得値のマーカーを付けます。

クリックは最も近い記録点を選び、同じ距離なら早い点に寄せます。波形や値を補間しません。番号は0〜最終点の整数だけを受け付け、空欄・小数・範囲外は現在の点を保持してエラーを表示します。端では前／次を無効にします。

## 入力行と結果の対応

系列入力では、実行時の表の行（表示は1から）、周期番号（初回0）を表示します。繰り返しならrow=k%rows／cycle=floor(k/rows)。繰り返しなしは最終行以降を保持し、その期間に「最終行保持」と表示。最後の行を初めて取得した点と、その後の保持を区別します。1行の繰り返しでも周期番号は進み、プラント状態は従来どおり継続します。

1回変更するstep入力では、「入力変更前／後」を実行した変更サンプルで判定します。選択後に入力表・repeat・点数・周期などを編集しても、カーソルは前回結果の入力・値・行・周期を使います。

カーソルは表示だけの操作です。モデル・履歴・比較条件JSON・結果JSON・CSVを変更せず、新たな計算も行いません。前回結果がある場合は比較計算中も確認でき、中止／失敗はその位置を保持。正常な設定復元やモデル／選択変更で比較表示が解除されると、カーソルと値も解除します。カーソルや出力切り替えは、条件が変わっていない遅延CSV読み込みを破棄する原因にしません。

カーソル位置は保存形式へ追加しません。比較条件を復元して再計算すると、同じ結果をサンプル0から確認できます。結果保存／検証や元モデルへの変換適用は[行列比較](matrix-comparison.md)、系列と繰り返しの意味は[系列比較](matrix-sequence.md)を参照してください。

## 描画と範囲

最大2001点を選択可能です。通常の波形描画で点を間引いていても、選択点は元データから読み、描画点に含めてマーカーを一致させます。軸は全記録値から求める既存の尺度を使い、大きな有限値も正規化した座標へ表示します。

表示線はサンプル点を結びます。サンプル間の連続曲線・離散保持の再構成、リアルタイム再生、元モデル全体の応答や一般的な精度・安定性の保証を追加する機能ではありません。テストと実画面の照合は[検証記録](validation.md)を参照してください。


[区間評価](matrix-range.md)で開始・終了サンプルを指定し、全出力の最大差・RMS・終端差・絶対差積分と、区間だけの実取得値JSON／CSVを保存できます。
