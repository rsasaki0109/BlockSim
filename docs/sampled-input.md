# Sampled Inputと任意の保持入力系列

Sampled Inputは表の各行を周期ごとに出力する入力ブロックです。ブロック図の種類一覧から追加し、入力系列をJSONの2次元配列で設定します。行がサンプル、列が成分です。たとえば幅2の`[[1,-1],[0.5,2],[0,-0.5]]`なら、t=0で[1,−1]、次の周期で[0.5,2]、次で[0,−0.5]を出力します。

## 時計と保存

`kind: "sampled_input"`、`values`、`sample_time`をモデルへ保存します。各値は次の取得時刻まで保持し、既定では表を読み終えると最後の行を保持し続けます。任意の`repeat: true`を保存すると、最後の保持区間の次に最初の行へ戻ります。`false`と省略は従来と同じで、正規化時はfalseを省略します。補間は行いません。ブロック設定の「入力系列を繰り返す」で切り替えます。1〜2001行、幅1〜64、全行が指定幅で有限値である必要があります。全展開済みモデルの表は合計200万セルまでです。WASMのモデルJSONは既存の1 MB上限も適用されます。

周期はグラフ刻みの1〜100000の整数倍です。行番号は整数の記録時計から計算するので、0.3秒などの浮動小数の丸めで切り替えが遅れません。RK45は各更新時刻で積分区間を分けます。内部段階・刻み棄却で行は進まず、連続状態は継続します。RK4でも同じ保持時計で動作します。通常のモデル保存／復元・JSON・Scope記録・ベクトルに対応します。

線形解析ではConstant・Step・Sineと同様に外部入力として扱います。選択した入力からScopeまでの伝達・状態空間を解析し、表のスペクトルや再生波形の周波数成分を計算するわけではありません。既存の連続／離散領域・周期・8状態などの制限を引き継ぎます。

## セルと行の編集

Sampled Inputの設定欄に「入力表を編集」を追加しました。表のセルで値を編集し、「末尾に行を追加」で0の行を追加、各行の「複製」で直後に同じ行を挿入、「削除」でその行を取り除けます。最後の1行は削除できず、2001行では追加・複製を無効にします。列数は信号幅と一致し、自動変更しません。

表と2次元JSON、入力CSVは同じ設定欄の入力表を使います。セル・行操作はJSONへ反映され、CSV読み込み・JSON編集は表へ反映されます。適用するまではモデル・Scope結果・履歴・保存済み設定を変更しません。適用は通常の1回の編集でUndo／Redo、モデル保存・再読み込みに対応します。表だけの独立したUndo履歴はありません。別のブロック選択や再描画では未適用の設定欄が元モデルへ戻る、従来の属性編集と同じ扱いです。

セルは小数・符号・指数表記の有限数値を受け付けます。空欄、途中の「−」、NaN／Infinity、16進表記、数値範囲超過は赤枠とサンプル／成分番号で知らせます。不正な文字は修正できるようセルに残し、JSON側は明示的なnullにします。古い有効値を適用することを防ぎ、不正値が残る間はモデル適用とCSV保存を拒否します。JSONから不正な表や幅の不一致を入力した場合は、表の操作を無効にし、JSONと幅の修正を案内します。

20行ずつ表示し、「前の20行」「次の20行」とページ番号で移動します。64列×2001行でも、一度に作る編集セルは最大1280個です。表の内側で横／縦にスクロールし、320pxの画面もページ全体を押し広げません。ページ移動はデータを変更しません。行番号は0から、ページ番号は1からです。

時刻欄は設定欄のサンプル周期×行番号を12桁へ丸めて表示する、繰り返し前の1周期の目安です。シミュレーション時計や時刻付きCSVの設定ではありません。無効な周期や表示計算の範囲超過は「—」。適用時には通常の整数倍周期検証を行います。

実行・解析中は表の操作を無効にします。セル編集はCSVの非同期読み込みの変更検知にも反映され、遅れて完了したCSVで値が上書きされません。元のモデル形式・周期保持・repeatの既定値・エンジン計算・保存形式は変更していません。

## 入力波形のプレビュー

Sampled Inputの設定欄で「入力をプレビュー」を押すと、未適用の表・幅・周期・繰り返しから入力だけを計算します。表、JSON、CSVのいずれで編集した値も対象です。元モデル・接続・プラントの状態・Scope結果・モデル履歴は変更しません。プレビューが成功しても、接続幅やモデル全体の適用可能性を保証するわけではありません。

繰り返しありは1〜3周期、初期値は2周期です。繰り返しなしは1周期へ固定します。N行・Ts・C周期なら終了時刻はN×C×Ts、記録数はN×C+1。終端を含み、繰り返しありでは終端の入力は先頭行、なしでは最後の行を保持します。1行の一定値にも対応します。

最初に元モデルの記録刻みで入力ブロックを検証し、周期が1〜100000の整数倍であることを確認します。その後、既存WASMエンジンのSampled Input→ScopeだけをTs刻みで計算します。最大2001行×3周期で6004記録点、最大64成分で384256記録成分です。モデルJSONの1 MBなど既存の境界も適用されます。Scopeの取得値から図を描き、JavaScriptで別の入力系列を生成して計算結果の代わりにすることはありません。

図は次の取得時刻まで水平に値を保持し、切り替えで垂直に変化します。表示の間引きや斜めの補間はしません。成分チェックボックスで最大16成分を表示でき、初期表示は先頭4成分までです。「取得サンプル」のカーソルで、表示中の成分の実記録値を確認します。表示を絞っても全成分の記録は残ります。

「プレビュー結果 JSON」はformat `blocksim.input-preview`、version 1で、実行時の設定・元の記録刻み・プレビュー用モデル・全取得時刻と全成分値を保存します。プレビュー周期数・表示成分・カーソル・計算結果は設定欄内の一時状態で、ブロック選択や再読み込みで解除されます。結果JSONの読み込み機能はありません。通常のモデル保存には、適用した表・幅・周期・repeatを保存します。

セル／JSON／CSV／幅／周期／repeatを変更すると計算中のプレビューを中止し、古い図と結果保存を無効にして再プレビューを案内します。表示周期数の変更も同じです。成分選択とカーソルだけの変更は計算結果を変えません。不正な値や周期はエラーとして扱い、前のプレビューを現在の設定と結び付けません。プレビュー中は通常実行・解析・結果ファイル検証と同時に計算せず、表とCSV操作を無効にします。専用の中止ボタン、遅れたWorker応答の破棄、階層内部・320px表示に対応します。

元の記録時計とTsごとの取得時計は、浮動小数の計算順により末尾ビットが異なる場合があります。テストでは対応する取得値の完全一致と時刻の許容誤差を照合しています。元モデル全体や応答、非均一な時刻列、入力の補間、実行状態の復元を行う機能ではありません。

## 表の行とプレビューを対応させる

プレビュー計算後、表の番号ボタンを押すと、その行に対応する取得点へカーソルが移動します。セルにフォーカスした場合も同じ行を確認できます。カーソルを動かすと逆に表の対応する行を強調し、必要なページへ移動します。スクロールは表の内側だけを動かします。プレビュー前は番号ボタンで計算が必要なことを案内します。

図には取得時刻の縦線、各表示成分の実取得値の点、次の取得時刻までの保持区間の帯を表示します。値はプレビューの実記録を使用し、表から波形を再生成しません。カーソル移動で波形パスを作り直さず、マーカーだけを更新します。取得サンプル番号と表の行番号は0から、表示する周期番号は1からです。

繰り返しありは現在表示中の周期を維持して表の行へ移動します。N行なら取得番号kは行k mod N、周期floor(k/N)+1に対応。N×Cの表示終端は先頭行・周期C+1の開始の取得点です。「表示終端」と明記し、次の保持区間の帯は描きません。終端で先頭行を選ぶと終端に留まり、他の行は最後の表示済み周期へ移動します。表示していない次周期の取得点を作りません。

繰り返しなしの終端は最後の行に対応します。そこで同じ最後の行を選んでも終端に留まり、別の行を選ぶとその取得点へ移動します。1行の一定値にも同じ規則を適用します。

ページ移動・行の確認・成分表示・カーソルは入力データ、モデル、履歴、Scope結果、保存したプレビュー結果JSONを変更しません。入力値／幅／周期／repeat／CSVを変更すると、以前のプレビューと行の強調を解除します。選択は設定欄内の一時状態でモデルJSONへ保存しません。表だけの選択からモデルを自動実行する機能ではありません。

## ブロックへ入力表CSVを読み込む

Sampled Inputを選択し、信号幅を指定して「入力表CSVを読み込む」を使います。1行が1サンプル、1列が1成分です。たとえば信号幅2なら次の表を読み込めます。

```csv
input_0,input_1
1,-1
0.5,2
0,-0.5
```

1〜2001行、1〜64列、UTF-8で1 MBまで。列数は設定欄の信号幅と一致する必要があります。見出しは省略可能で、1列なら`input`、複数列なら0から順番に`input_0,input_1,…`。小数・符号・指数表記、LF／CRLF、先頭BOM、前後の空白に対応します。空のセル、途中の空行、列数の不一致、引用符、時刻列、任意の列名、非有限値、16進表記は拒否します。

読み込みは設定欄の入力系列だけを置き換えます。「ブロック設定を適用」するまでモデル、接続、Scope結果、履歴、保存済み設定は変わりません。適用は通常の1回の編集で、Undo／Redoに対応します。列数の自動変更は行いません。周期・繰り返し・表示名・位置もCSVで上書きしません。幅の変更は既存の接続幅との整合を含め通常のモデル検証を通します。

「入力表CSVを保存」は現在の設定欄の表を、指定幅と有限値で検証して見出し付きCRLFで書き出します。未適用の編集も対象です。周期と繰り返しも保存するにはモデルJSONを使用してください。Scope結果CSVや離散化比較の結果CSVとは別の形式です。スカラーの比較入力CSVは従来どおり100 KB・2行以上で、このブロックCSVは1行の一定値にも対応します。

不正なCSVは設定欄と直前の実行結果を維持します。読み込み中に設定欄を編集、別ブロックへ移動、モデルを適用／Undo、別のCSVを読み込み、実行・解析・ファイル検証を開始した場合、遅れた読み込み結果を破棄します。実行・解析中はCSV操作を無効にします。通常のモデルJSONの1 MB上限と合計200万入力セル上限は引き続き適用されるため、CSVを読めてもモデル全体が上限を超える場合は適用できません。

[2列CSV](../samples/discrete/vector-input.csv)と[モデル](../samples/discrete/vector-input.json)を用意しています。GUIサンプル「ベクトル入力表CSV」を選び、CSVを読み込んで適用すると、Ts=0.1sで3行を周期再生します。各10記録区間の入力は上の行を保持し、t=0.3sで最初の行へ戻ります。繰り返しをオフにするとt=0.2s以後は[0,−0.5]を保持します。

## 離散化比較

連続TransferFunctionを選択し、比較入力を「任意のサンプル入力系列」にします。1成分の値をJSON配列で入力するか、「1列の入力CSVを読み込む」で読み込みます。繰り返しなしでは比較点数は配列の長さから決まり、2〜2001点。「入力系列を繰り返す」を有効にすると、1〜2001行のJSON配列を周期再生し、比較点数を2〜2001点で別に指定できます。CSV読み込みも指定した比較点数を保持します。1行の一定値はJSON配列で入力します（入力CSVは従来どおり2行以上）。部分的な周期で終了することもできます。終了時刻は(点数−1)Tsです。両モデルで同じSampled Inputを使用し、実入力をScopeで記録して全記録点の一致・区間内の保持・指定系列との一致を確認します。

CSVは1行に1数値、任意の見出しは`input`だけです。小数・符号・指数表記、LF／CRLF、先頭BOMに対応します。前後の空白行は除き、途中の空行、複数列、引用符、NaN／Infinity、16進表記を拒否します。100 KBまで、2〜2001値です。[入力CSV](../samples/discrete/sequence-input.csv)・[設定JSON](../samples/discrete/sequence-comparison-plan.json)・[モデル](../samples/discrete/sequence.json)を用意しています。

比較設定はversion 1の任意フィールド`input: {kind: "sample_sequence", values: [...]}`です。`repeat`は任意のbooleanです。省略／falseなら保存した点数と系列長が一致する必要があります。trueなら行k mod Nを使用し、初回は行0、最初の戻りはt=N Tsです。入力だけを繰り返し、プラントの状態はリセットしません。結果JSONには実入力を保存し、結果CSVは既存6列に`input,sample_index`を追加します。繰り返しtrueの場合のみ、0から数える`cycle_index,row_index`も追加します。結果CSVは入力CSVと異なる形式です。古い単位ステップ・保持Step・保持正弦波の設定と結果形式は維持します。

比較は選択した伝達関数を単独・初期状態0で動かすスカラー応答です。元モデルの入力・接続・時計やScope結果は変更しません。結果の線はサンプル点を結び、サンプル間の保持波形を再構成しません。計算予算・中止・保存済みの実行条件の保持は[共通仕様](conversion-comparison.md)と同じです。入力CSVを編集・読み込みしても前回の図・結果JSON・CSVは実行時の系列のまま。設定JSONは現在のフォームを保存します。不正なCSVはフォームと前回結果を保持します。

## 数値検証

`source scripts/rust-env.sh`の後、`cargo run --locked --example sequence_comparison`で[検証JSON](sequence-comparison-validation.json)を再生成できます。全4ケースは101点・単独・初期状態0です。

| 対象 | 方式 | 最大絶対差 | RMS差 |
| --- | --- | ---: | ---: |
| 1/(s+1)²、Ts=0.2s、複数回増減する入力 | ZOH | 1.2043e−12 | 6.3309e−13 |
| 同上 | Tustin | 0.03688056 | 0.02009072 |
| 1+1/(s+1)、Ts=0.1s、0.75／−0.5／0.25の反復 | ZOH | 2.8311e−15 | 1.1291e−15 |
| 同上 | Tustin | 0.03571429 | 0.02585483 |

独立した連続の保持区間の解析更新式と、Tustinの差分式は[保持正弦波仕様](sine-comparison.md)の式を任意のu[k]へ適用します。連続の解析式との最大誤差は1.202e−12以下、独立した離散式とは2.887e−15以下でした。Rustでは幅2の保持・最後の行・不正行／周期／セル上限、RK45棄却と高速プラントの解析式、伝達解析での外部入力扱いも検証。実WASMでは2001点、設定／結果の保持、CSV／JSON復元、ベクトル保存／再読み込み、遅延したCSV読み込みの破棄、320px表示を確認します。

この検証は保持入力のサンプル時刻の比較です。非均一な時刻列、表の補間、任意のCSV列指定、非ゼロ初期状態、元モデル全体の変換比較、任意の高次係数・サンプル間の一致は保証しません。
