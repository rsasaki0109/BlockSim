# 連続伝達関数のTustin離散化

[単位ステップ比較](conversion-comparison.md)で、初回の直接項を含む変換前後の時間応答の差を確認・保存できます。

連続TransferFunctionの設定欄で「連続 → 離散：Tustin法」を使います。周期と任意のプリワープ角周波数を入力し、**変換係数を確認**した後に **離散ブロックへ変換**します。適用済みの係数が対象です。未適用の分子・分母などの編集は先に「ブロック設定を適用」してください。

変換先は [Discrete TransferFunction](discrete-transfer.md)。同じID・表示名・幅・位置・接続を保ち、1回のUndoで元へ戻せます。記録時計、計算方式、他のブロック、解析領域は変更しません。周期は記録時計の整数倍である必要があります。変換後の周期・係数・ゼロ初期状態は通常のモデル保存／復元や実行結果ファイルに含まれます。変換前の連続係数・入力したプリワープ条件をモデルに履歴として追加する機能ではありません。元のモデルを残す場合は変換前に保存してください。

## 変換式と範囲

連続系のsの降べき順で指定した0〜8次のproperな実係数N(s)/D(s)へ、以下を代入します。

```text
s = k (z−1)/(z+1)
k = 2/Ts                             （通常Tustin）
k = ωp/tan(ωp Ts/2)                  （プリワープ）
```

分母次数nに対して(z+1)^nを掛け、zの降べき順の分子・分母を展開し、分母の先頭を1へ正規化します。短い連続分子は高次側を0で補います。分子・分母を共通の正の尺度で扱い、k≥1なら1/kのべきを使い、巨大なk^nの中間計算を避けます。次数を保持し、極零相殺・最小実現は行いません。

例えば `1/(s+1)`、Ts=0.1sは分子 `[1/21,1/21]`、分母 `[1,−19/21]`。`1/s` は分子 `[0.05,0.05]`、分母 `[1,−1]`。`1/(s+1)^2` は分子 `[1/441,2/441,1/441]`、分母 `[1,−38/21,361/441]` です。通常の厳密にproperな連続系にも離散の直接項が生まれます。

初期状態の変換は未対応です。GUIでは全成分の初期状態が0のときだけ変換でき、非ゼロなら以前のモデル・結果を保持して拒否します。連続companion状態を、同じ数値の離散companion状態へコピーしません。

プリワープは `0<ωp<π/Ts`（rad/s）。その1つの物理角周波数で連続／離散の応答を一致させます。他の周波数まで一致させるものではありません。周期・周波数の非有限値、角度の数値的な未解決、変換項や正規化係数のアンダーフロー／オーバーフローは拒否。変換後の分母先頭の絶対値が、その計算項の絶対値和に対して1e−12以下なら未解決として拒否します。例えば連続極がkにある場合は、無限遠へ移る極を勝手に次数削減しません。

## 保持する結果と接続

係数確認だけではモデル・時系列・解析結果・編集履歴を変更しません。確認後に周期・プリワープ入力やモデルを変更した場合は再確認が必要です。適用すると既存の編集処理で結果を無効化し、再実行します。実行・解析・ファイル照合中は変換を開始／適用できません。階層の完全IDで対象を区別し、ベクトルの各成分へ同じ変換係数と独立したゼロ状態を設定します。

直接項が生まれるため、連続の状態で切れていた帰還が代数ループになることがあります。確認段階で変換先モデルの診断を行い、直接伝達の循環があれば元のモデルと結果を保持して拒否します。接続を自動で切断したり、Delayを挿入したりしません。作成途中のモデルの未接続・Scope不足は、通常の実行前診断で確認してください。

## 周波数と時間の意味

単位円上の角度Ω=ωTsでは、連続系の角周波数は **k tan(Ω/2)** へ対応します。周波数軸は非線形に歪みます。変換したモデルの解析では、離散領域を明示して選び、同一周期・最大8状態など既存の制限に従います。

Tustin変換はゼロ次ホールドによる厳密な離散化ではありません。時間のStep応答を連続系の同時刻の応答と完全一致させず、サンプル間は既存の離散ブロックの出力を保持します。例えば2次ローパスのTs=0.1sでは、初回の出力は1/441です。連続系の初回0との差を誤差ゼロと表示しません。

## 数値検証

[tustin.json](../samples/discrete/tustin.json) またはサンプル「連続 → 離散：Tustin変換」を使います。`cargo run --locked -p blocksim-core --example tustin` は `1/(s+1)^2` のTs=0.1／0.2s、0.2sでωp=5rad/sの3ケースを実際の離散ブロックとして実行します。

8秒・801記録点のStepを独立した `1+(A+Bn)α^n` の式と比較し、最大誤差7.78e−15未満。201複素点を `G(j k tan(ωTs/2))` と比較し、最大誤差1.85e−14未満。[数値JSON](tustin-validation.json) に係数・初回6サンプル・全体誤差を保存しています。

| Ts (s) | プリワープ | 物理角周波数5rad/sでの連続系との複素差 |
|---:|---|---:|
| 0.1 | なし | 0.001563381532 |
| 0.2 | なし | 0.006150368849 |
| 0.2 | 5rad/s | 1.57e−17未満 |

Rustでは1〜8次の独立した複素多項式、静的Gain・積分器、1e300倍の非モニック係数、安定／境界／不安定な極の写像、相殺された内部極、RK4／RK45の実Stepと2つの独立した台形積分フィルターも照合。GUI／実WASMでは確認・適用・Undo／Redo・保存／再読込、プリワープの実Bode、失敗時の保持・実行中の拒否、階層・ベクトル・320pxを確認しています。有限精度・選んだモデルの検証で、一般的な誤差や安定性の証明ではありません。

matched pole-zero、非ゼロ初期状態の変換、モデル全体の一括変換、プリワープ条件の履歴保存、自動線形化は未実装です。

方式選択の [ZOH](zoh.md) は、保持入力に対するサンプル時刻の応答を合わせる別の方式です。
