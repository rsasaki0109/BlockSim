# 同一周期の離散周波数応答 / Bode

周波数応答パネルの「解析領域」を **離散系・同一周期（単位円）** にすると、選択信号源の1成分から選択Scopeの1成分への応答を解析します。既存の [離散状態空間](discrete-state-space.md) と同じサンプル更新順序・現在の接続を使い、各角周波数で以下を解きます。

```text
z = exp(j ω Ts)
G(z) = C (zI − A)⁻¹ B + D
```

ωはrad/s、Tsは秒、Ω=ωTsはrad/sampleです。サンプル時刻の入力・出力の伝達を評価します。ゼロ次ホールドのsinc、連続プラントの応答、サンプル間の波形再構成は加えません。振幅はdB、位相は度で表示します。

## 対象・範囲

Scope祖先の関連128成分変数・最大8状態、同じsample_timeのDelay／Discrete TransferFunction／無制限離散PID、静的TransferFunction・Gain／Sum・境界・Mux／Selectorなどが対象です。周期はdtの整数倍で、値自体も同じである必要があります。離散時計を持たない静的な系だけならTs=モデルdtです。次数0の離散伝達関数も設定周期を使います。連続状態、異なる周期、非線形・制限付きPID／Saturation、多入力Product、代数ループは解析前に拒否します。選択外の枝と成分は除外します。

他の信号源の変動と初期条件はゼロです。選択信号源の振幅・位相・オフセット・Step設定は、この単位変動の応答を変えません。元モデル、時間応答、状態空間結果、編集履歴は変更しません。

角周波数は `1e−9 ≤ 最小 < 最大 ≤ min(1e9, π/Ts)`、対数間隔2〜2048点です。Nyquist角周波数π/Ts以下の単位円の上半分を評価し、上限を超える場合は拒否します。UIとCSVへ周期・Nyquist角周波数を明記し、カーソルには正規化角周波数Ωも表示します。DC=0は対数軸へ含めません。

最大がちょうどNyquistなら、`z=−1+j0` を厳密に使います。sin(π)の丸め誤差で、Nyquistの極が巨大な有限応答に見えることを避けます。位相は既存の有効な標本間の折り返し補正を使い、欠測・零応答でリセットします。粗い標本では回転を取り逃す場合があります。

縦軸の範囲が1e−9×max(1,縦軸の値の絶対値)以下なら0.08の余白を確保し、振幅1の丸め誤差を大きな変動のように描きません。計算値・カーソル・CSVは変更しません。

## 数値・欠測

時間シミュレーターの実際のPID step・同期Delay評価を単位状態／入力で行列化し、固有値や特性多項式の求根を経由せずに使います。スペクトルの再構成が未解決でも、有限な行列の応答は計算できます。状態削除・極零相殺・最小実現はしません。

各点は行で正規化した複素行列の部分ピボット消去で解きます。ピボット1e−12未満、非有限値、線形方程式の相対残差1e−10超過、単位円角の表現不能、応答振幅のオーバーフローをエラーにします。点数×max(状態数,1)³を2000万以下に制限します。最大8状態・2048点の上限内ではこの予算を満たします。

特異／悪条件の点は数値をnullにし、曲線を結ばずCSVへエラーを残します。零応答は振幅0、dB・位相はnull、状態はzeroです。入力が関係しない場合のB・Dはゼロですが、内部状態は残ります。出力へ影響しない内部極が単位円上にあっても、zI−Aが特異なら欠測にします。既約伝達関数の極零相殺で値を補う機能ではありません。

Bodeが計算できても、安定な定常応答・安定性・チューニングを保証しません。不安定な系も、特異でない周波数点では形式的な応答を持ちます。内部安定性は別の状態空間パネルで単位円に対して数値判定します。離散系のゲイン／位相余裕は、開ループを明示した場合に [離散余裕仕様](discrete-margins.md) の有限帯域の候補として計算します。連続系で計算済みの結果を領域フォームの変更だけで離散結果に付け替えません。

## 保存とCSV

専用 `blocksim.frequency` version1設定へ任意の `domain:"discrete"` を加えます。省略・明示したcontinuousは従来の連続系、未知の領域・不正キー・離散系の開ループ指定は拒否します。ファイルはモデル・source／scope／成分・範囲・点数を含み1 MBまで。通常の未保存確認でモデルを置き換え、領域と条件を復元した後に明示的に解析します。

離散CSVは既存の13列へ `sample_time_s、nyquist_rad_s、omega_rad_sample` を追加し、全標本へ同じ実行済み周期・上限を保存します。エラー・零応答の点も省略しません。連続系の旧CSVは13列のままです。モデル形式・旧設定ファイル・連続系の解析式は変えません。結果は再読込で消え、専用設定から再実行できます。

Worker中止、古い返答・遅延ファイルの無視、他の計算との同時実行防止、モデル編集／Undoでの無効化は既存のBodeと共通です。フォーム・領域変更や不正な条件では直前の有効な結果を保持し、CSVにもその実行済み条件を使います。

## サンプルと検証

[frequency-plan.json](../samples/discrete/frequency-plan.json) を「解析設定を読み込む」で復元します。Ts=0.1s、Nyquist=31.4159265359rad/s、実際の2段Delay負帰還は `G(z)=z/(z²−0.8z+0.64)`。1サンプルDelay単体は `G(z)=1/z`、振幅1・位相−ωTsで、Nyquistでは−180度です。

`cargo run --locked -p blocksim-core --example discrete_frequency` は各201点の複素応答を独立した上記の解析式と照合し、実シミュレーターの正弦波入力を24〜40秒の160サンプル時刻（20周期）でsin／cosへ投影して比較します。

| ケース | 最大複素誤差（201点） | 最大方程式残差 | 実時間応答の調和成分との誤差 |
|---|---:|---:|---:|
| 2段Delay負帰還 | 1.84e−15未満 | 1.70e−16未満 | 1.61e−14未満 |
| 1サンプルDelay | 2.78e−16未満 | 1.15e−16未満 | 6.68e−15未満 |

[数値JSON](discrete-frequency-validation.json) に詳細を保存しています。離散PIDの後退Euler積分と後退差分フィルターの独立式、正弦波による実更新、単位円上・Nyquistの特異点、無影響の内部状態、静的・零応答、階層・ベクトル・上限・形式・GUI保存をテストしています。上記は選んだ有限周波数・時間窓の結果で、任意モデルの精度を保証しません。

Nyquist安定性判別、異なる周期のlifting、連続プラントとの混在解析、Discrete TransferFunctionブロック、9状態以上・MIMO・全モデル解析、非線形の線形化、最小実現は未実装です。

[Discrete TransferFunction](discrete-transfer.md) を使って離散IIR／FIRの係数と初期状態を直接指定できます。
