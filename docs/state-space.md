# 接続された連続線形部分の状態空間

「接続された線形部分の状態空間 / 安定性」は、**選択したScope成分の祖先にある内部実現**を現在の接続のまま取り出します。SISOの `ẋ=Ax+Bu、y=Cx+Du`、状態の順序、Aの固有値と数値的な内部安定性を表示します。仮定した負帰還へ置き換える [単一伝達関数解析](pole-zero.md) と区別します。

## 対象

Scopeの選択成分からフィードバックを含む祖先をたどり、階層は完全なID、Mux／Selectorは成分で区別します。関連成分128変数、内部連続状態8個まで。超えた場合は解析前に拒否し、状態を黙って減らしません。

Gain／Sum、Integrator／FirstOrder／TransferFunction、無制限の連続PID、Mux／Selector、境界Input／Output、Scopeが対象です。無制限Saturationと入力1本のProductは恒等写像。関連する制限付きPID／Saturation、多入力Product、離散PID／Delay、代数ループは拒否します。

無関係な枝・選択外の成分は除外するため、**モデル全体の安定性ではありません。** 選択外に不安定な状態や非線形の枝があっても対象外です。モデル全体は既存の実行前検証を通る必要があり、時計・記録予算・RK4の条件は維持します。

初期条件と他の信号源の変動はゼロ。選択信号源の振幅・位相・オフセットに依存せず、単位変動に対する行列です。一般の非線形モデルを動作点で線形化しません。状態削除・極零相殺・最小実現は行わず、入力が届かない状態、出力に無影響の状態、ゼロGainを通る祖先も残します。PIDはKi／Kdが0でも積分IとフィルターFを保持します。出力の整定と内部実現の漸近安定は同じではありません。

選択入力がScopeの祖先にない場合はB・Dがゼロになり、入力が関係しないことを表示します。祖先の状態は削除しません。

## 行列と数値評価

時間応答と同じ出力・微分式を、関連成分の解析用コピーで単位状態・単位入力について評価します。**有限差分の差や微小刻みは使いません。** 元モデル・時系列・履歴は変更しません。状態は祖先をたどった順に、ブロックID・ラベル・成分・内部状態番号を併記します。TransferFunctionはcompanion状態、PIDは重み付き積分／誤差フィルター、FirstOrderは出力、Integratorは積分入力です。状態や行列の物理単位は自動推定しません。

1. 正の `scale=max|Aᵢⱼ|`（Aがゼロ／状態なしでは1）でS=A/scaleを作ります。非ゼロ要素のアンダーフローでは行列を保持し、スペクトルと安定性を未解決にします。
2. Faddeev–LeVerrier法で `det(zI−S)` を求め、Cayley–Hamilton残差1e−8以下を確認します。行列積の非ゼロ項のアンダーフロー、非有限値や残差超過は判定不能です。
3. 特性多項式の根を [既存の求根](pole-zero.md) で検証します。独立にzI−Sの行列式を、各行の `|z|+Σ|Sᵢⱼ|` で正規化し、残差1e−8以下を確認します。消去のピボット1e−14未満は残差の分解能で特異と扱います。
4. 正のscaleを掛け、根を実部1/s・虚部rad/sへ戻します。座標のオーバーフロー／非ゼロ成分のアンダーフローでは部分的な根を返しません。
5. 特性多項式のRouth表を求根とは独立に評価します。正の変数倍率は右半平面の個数を変えません。境界／近傍・小さなピボット・個数未確定を安定へ置き換えません。

特性多項式の検証が未解決なら係数null・根は未解決・安定性は判定不能です。座標の求根だけが未解決でも、検証した特性多項式からRouth表を評価できる場合は独立に表示します。状態0個ならA・B・Cは空、Dだけで、有限の極はありません。

残差は必要な数値確認であり、**固有値の座標誤差、重根の精度、厳密な安定性の証明を保証しません。** 特性多項式を経由するため、非正規性・極端な尺度・境界付近に制約があります。汎用の大規模QR固有値ソルバを実装した意味ではありません。

## 保存・出力

専用 `blocksim.state-space` version1設定ファイル（モデル＋source／scope／各component、1 MBまで）で保存・復元します。読み込みは通常の未保存確認を経てモデルを置き換え、その後に明示的に解析します。通常のモデルJSONへ解析条件を加えず、結果は再読み込みで消えます。

CSVは全行列要素・状態順序・固有値・残差・注記・判定を保存します。「行列・極の結果JSON」は実行済み結果の書き出し用で、設定ファイルとは別です。結果JSONの読み込み・照合は行いません。Workerで解析し、時間実行・Bode・単一伝達関数解析・掃引・結果確認とは同時に開始しません。フォーム変更／中止後は実行済み結果とCSV／JSONを保持し、モデル編集／Undoで無効化します。不正な設定・対象・上限は以前の有効なモデルと結果を保持し、古い返答／遅延ファイルを反映しません。有限の係数から評価がオーバーフローする場合は解析中エラーです。

## 接続済み負帰還の例

[feedback-plan.json](../samples/state-space/feedback-plan.json) またはモデルサンプル「接続済み負帰還の状態空間」を使います。実際の辺はsource→Sum→Gain(K)→1/[s(s+1)(s+2)]→Scope、プラントからSumへ負のフィードバック。行列は `A=[[-3,-2,-K],[1,0,0],[0,1,0]]、B=[K,0,0]、C=[0,0,1]、D=0` です。

K4は漸近安定、K6は境界（−3、±j√2）、K8は右半平面2個・不安定。`cargo run --locked -p blocksim-core --example state_space` はCardano式と極を照合し、元の接続済みモデルのRK45 Step応答100秒・2001点を独立した部分分数式と比較します。

| K | 最大極誤差 | 最大時間応答誤差 | 最大絶対出力 |
|---:|---:|---:|---:|
| 4 | 7.79e−16未満 | 2.11e−9未満 | 1.700132194 |
| 6 | 2.35e−15未満 | 3.09e−8未満 | 1.904529244 |
| 8 | 2.23e−15未満 | 5.77e−5未満 | 3359.131684 |

詳細は [state-space-validation.json](state-space-validation.json)。不安定系の誤差は有限の100秒窓の値で、任意のモデル・期間・尺度で同じ精度を保証しません。独立した実2n×2n解法による周波数応答と既存Bodeの全201点も照合しました。PIの無影響フィルター極−20、微分項、内部Scopeの直接伝達、相殺された不安定極、結合Integrator、8段一次遅れ、階層・Mux／Selector・ベクトル、無関係な不安定／非線形枝、静的実現、上限・極端な尺度を検証しています。

全Scope／全モデルを同時に含む解析、MIMO、8状態を超える固有値解析、状態空間ブロックの追加・編集、離散／混在系、非線形の線形化、最小実現・伝達零点・Nyquistは未実装です。
