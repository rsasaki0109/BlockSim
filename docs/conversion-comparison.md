# 離散化前後の単位ステップ比較

ブロック図で連続TransferFunctionを選択し、方式・変換周期・任意のプリワープを入力して「応答を比較」を押します。係数確認や離散ブロックへの適用をせずに比較できます。上の係数編集は先に適用してください。

比較対象は選択した伝達関数を単独で動かした、初期状態0・入力1のスカラー応答です。元モデルの接続、入力源、時計、終了時刻、幅別の初期状態を再現しません。各成分が同じ係数を使うベクトルブロックでも、比較は1成分だけです。元モデルとそのScope結果・基準を変更しません。

## 時計と差分

連続側はRK45（絶対／相対許容誤差1e−11、最小内部刻みTs×1e−12、最大内部刻みTs/10）、両側の記録刻みはTs/10です。離散側は実際のDiscrete TransferFunctionを実行します。変換周期Tsの各時刻だけを抽出し、補間せずに比較します。点数は初回を含む2〜2001、終了時刻は(点数−1)Tsです。

Δ=離散−連続として、初回も含めた最大絶対差、RMS（点数で平均）、終点の符号付き差を表示します。結果JSONは台形則の∫|Δ|dtも含みます。実線は離散、破線は連続。表示線はサンプル点を結んだもので、サンプル間の保持出力や連続応答を描いているわけではありません。

単位ステップはt=0から一定の入力1で、各区間の保持入力です。ZOHではこの入力のサンプル時刻の一致を確認できます。有限精度とRK45誤差があるため差は厳密な0を保証しません。Tustinの時間応答は一般に異なり、初回の直接項による差も隠しません。入力や周期を変更した他モデル、高次の数値条件、フィードバック、サンプル間の一致まで保証する比較ではありません。

## 保存と中止

- 「比較設定 JSON」は現在の方式・元係数・Ts・プリワープ・点数を保存します。形式は`blocksim.conversion-comparison`、version 1。[サンプル](../samples/discrete/comparison-plan.json) は`1/(s+1)²`、ZOH、Ts=0.2s、101点です。
- 読み込みは100 KBまでで、未知のフィールド、範囲外の点数、係数、周期、プリワープを拒否します。同じ係数の連続ブロックを選択して読み込んでください。初期状態は0である必要があります。正しい設定を読み込むと前回比較を消し、再実行を待ちます。元モデルは変更しません。
- 「比較結果 JSON」は実行した条件、変換後の係数、全点の連続／離散値と差分指標を保存します。条件を編集しても、前回の図・CSV・結果JSONは実行時の条件のままです。実行条件を図の説明に表示します。結果JSONの再読み込みには対応しません。
- 「比較 CSV」は方式・Ts・時刻・連続値・離散値・Δの全点です。設定ファイルは現在のフォーム、結果ファイルは前回の実行条件を保存する点に注意してください。
- 別Workerで計算し、各実行1000万、合計2000万成分評価を上限とします。2つの結果が揃うまで途中結果を表示しません。中止・モデル編集・選択移動でWorkerを終了し、古い返答を破棄します。通常実行・解析・結果ファイル確認と同時には開始できません。失敗した比較や不正な読み込みは前回の良い比較結果を保持します。

## 数値検証

`source scripts/rust-env.sh`の後、`cargo run --locked --example conversion_comparison`で[検証JSON](conversion-comparison-validation.json)を再生成できます。各ケースは101サンプルです。

| 伝達関数 | 方式 | Ts (s) | 最大絶対差 | RMS差 |
| --- | --- | ---: | ---: | ---: |
| 1/(s+1) | ZOH | 0.2 | 3.3873e−13 | 1.0232e−13 |
| 1/(s+1) | Tustin | 0.4 | 0.1666667 | 0.02285472 |
| 1/(s+1) | Tustin | 0.2 | 0.09090909 | 0.01597096 |
| 1/(s+1) | Tustin | 0.1 | 0.04761905 | 0.01121330 |
| 1/(s+1)² | ZOH | 0.2 | 1.2819e−12 | 1.9589e−13 |
| 1/(s+1)² | Tustin | 0.2 | 0.03545816 | 0.01092649 |

独立した連続式は1−exp(−t)、1−(1+t)exp(−t)。一次Tustinの離散式は`1−2/(2+Ts)×[(2−Ts)/(2+Ts)]^k`です。一次の最大差は初回の`Ts/(2+Ts)`で、この例ではTsを小さくすると減少します。周期依存の一般保証ではありません。2次Tustin初回は`1/121 ≈0.008264463`です。2次Tustinの独立離散式との検証は行っておらず、JSONの対応値はnullです。

Rustでは独立式と周期の変化、ZOHのサンプル間の不一致を検証します。Vitestではファイル境界、時計の違い・非有限値の拒否、初回差と符号を確認。Chromiumでは実WASMと独立式、保存／読み戻し、元モデル／結果の保持、失敗・中止・編集、狭い画面を確認します。
