# 比較区間の最大差へ移動

行列応答の比較が完了したら「比較する区間を指定」を開き、両端のサンプル番号を指定します。「全出力の最大差へ移動」は、区間内の全取得点・全出力から `|離散−連続|` が最大の点を選びます。カーソルと表示する出力を同時に切り替え、時刻・実入力・連続／離散の値・符号付きΔを表示します。

各出力の指標表にも「最大差の取得点」があります。そのボタンは同じ区間の該当出力だけを検索します。時刻とサンプル番号は元の結果の番号です。1点の区間も使用できます。全区間へ戻したら、全結果から検索できます。

検索は表示の丸め値や間引いた線ではなく、実行済みの生値から行います。最大値が同じなら早いサンプル、同じサンプルなら小さい出力番号を選びます。符号の大小ではなく絶対値で比較し、移動後のΔは符号を保持します。最大2001点×8出力を対象にします。

出力ごとの単位や尺度が異なる場合、全出力の最大差はその生値の絶対値を比較します。正規化・重み付けはしません。適切な出力ごとの評価にも表のボタンを使えます。

区間の外へ移動したり、区間を変更したりはしません。元モデル・Scope結果・編集履歴・実行条件・全結果／区間JSONとCSVの内容を保持し、再計算しません。条件を編集しても表示中の実行済み結果を検索します。計算中も前回の結果を確認でき、保存は計算の終了を待ちます。中止や失敗は前回の結果と移動先を保持します。

空欄・小数・逆転・範囲外の区間入力、有限範囲を超える区間指標がある場合は、最大差への移動を無効にします。前回の区間表示を保持し、有効な両端へ修復すると再び操作できます。

移動先は[作業状態JSON](matrix-session.md)へ他の閲覧位置と同じ形式で保存できます。復元は全結果を現在のWASMで再計算して一致を確認してから行います。最大差は復元した結果と区間から再び検索します。既存の保存形式へ新しい必須項目は追加していません。

この最大差は取得点だけの最大値です。点と点の間にある真の最大誤差、一般的な精度・安定性、出力の尺度をまたぐ比較の妥当性を保証しません。[実測値](matrix-peak-validation.json)と[検証記録](validation.md)を参照してください。
