# 伝達関数の極・零点と安定性

ブロック図エディタの「伝達関数の極・零点 / 安定性」は、**選択した連続 TransferFunction の1成分の内部実現**を解析します。幅が2以上でも係数は各成分で共通なので、根と個数は1成分分を表示します。初期状態や入力振幅は根に影響しません。

## 解析対象を指定する

「伝達関数」で階層を含む正確なブロックIDを選びます。モデル全体は通常の実行前検証を通る必要がありますが、解析するのは選択ブロックだけです。**他のブロックや接続を含む、ブロック図全体の安定性の判定ではありません。** 別の場所に不安定なブロックがあっても選択ブロックの結果は変わりません。

- **選択ブロック N/D**：分子 N(s) の零点と分母 D(s) の極を求めます。元の係数を使います。
- **仮定した単位負帰還 N/(D+N)**：選択ブロックを開ループ L(s)=N(s)/D(s) と仮定し、T(s)=L(s)/(1+L(s)) を解析します。NとDを共通倍率で正規化してD+Nを求め、分子はNのままです。既存の辺を切断・追加したり、モデルの係数を書き換えたりしません。複数ブロックのループを自動抽出する機能ではありません。

直接ゲインが−1の負帰還は代数方程式が特異になるため拒否します。D+Nの先頭が `|D₀+N₀| ≤ 1e−12(|D₀|+|N₀|)` になる場合も、因果的な通常の実現を定義できないか悪条件として解析前に拒否します。非ゼロ係数の正規化がアンダーフローする極端な範囲も拒否します。失敗時は以前の有効なモデル・結果を保持します。

**極零相殺・最小実現は行いません。** 例えばN=s−1、D=(s−1)(s+2)では零点1と極1を両方残し、内部実現を不安定と判定します。入出力の既約な伝達関数は1/(s+2)ですが、そのBIBO安定性をここで判定しているのではありません。Nが零多項式でも、内部状態の分母の極は残します。

## 求根と表示

実係数の0〜8次を扱い、分子の先頭の0と原点の重複根を区別します。定数多項式には有限の根がありません。零多項式は全sで0になるため、有限の孤立した零点集合を定義せず、`identically_zero` とします。

1次・2次は解析式、3〜8次は変数スケーリングしたAberth型の同時反復を使います。最大4回の初期値、各800回までの更新で打ち切ります。元の浮動小数点係数が二項係数による `(s−r)^n` と**完全一致**する実重根は直接求めます。近似GCDや許容誤差による相殺・重複度の仮定はしません。

全根の集合について、次の両方を満たした場合だけ `verified_residual` を返します。

1. 各根の正規化した多項式残差 `|P(z)| / Σ|aᵢ||z|^(n−i) ≤ 1e−9`。変数・係数の共通スケーリング後の等価な式で検証します。
2. 根から再構成したモニック係数の誤差が1e−7以下。非ゼロ係数ではその係数の絶対値（最小1e−300）で割り、0の係数では絶対誤差を使います。

満たさない場合や、変数スケールの対数が−700〜700を外れる場合、係数のアンダーフロー・非有限な根では `unresolved` とし、部分的な根を返しません。**残差が小さくても根の座標誤差は保証できません。** 重根・近接根は特に敏感で、近接した根や重根の直接認識を警告に残します。根の5%×(1+絶対値)以内の近接判定は警告のためだけで、相殺や安定性の判定には使いません。

複素s平面では極を×、零点を○で表示します。重なった根は表に個数分を残します。実部は1/s、虚部はrad/s。GUIの表は有効数字7桁、CSVは実際の数値の精度を保持します。巨大な有限値でも座標変換は先に割り算を行い、座標のオーバーフローを防ぎます。

## 安定性の数値判定

求根の座標の符号だけで安定性を決めず、**解析した分母の独立したRouth表**を使います。係数を最大絶対値で正規化し、表の各行も正の倍率でスケーリングします。閾値は1e−10です。

| 結果 | 意味 |
|---|---|
| 漸近安定（数値判定） | 解決した表の符号変化がなく、境界を示す行がない |
| 不安定（数値判定） | 解決した表に符号変化がある。右半平面の極の個数も表示 |
| 境界／近傍 | 正確なゼロ行に対する補助多項式の微分を用い、右半平面0個の場合。または行全体が小さいが非ゼロで、境界付近として個数は未確定の場合 |
| 判定不能 | 小さな先頭ピボット、係数や表の悪条件などで符号を確定できない。個数は未確定 |

正確なゼロ行は対称な根を含むため、常に虚軸の根だけとは限りません。例えばs²−1では不安定・右半平面1個、s²+1では境界・右半平面0個です。先頭だけがゼロに近い行へ任意のεを代入して安定と判定しません。非ゼロの小さな行は正確なゼロ行と扱わず、**境界／近傍・個数未確定**にします。

これは浮動小数点の数値評価で、厳密な区間演算による証明ではありません。係数や時間単位の尺度、境界付近では判定不能・近傍となることがあります。求根未解決でもRouth表が解決する場合は判定を独立に表示し、求根の状態を隠しません。次数0は内部動的状態がなく、有限の極なしとします。

## 保存と実行

専用の `blocksim.pole-zero` version1ファイルにモデルと `{block, mode}` を保存します。1 MBまで。読み込みは通常の未保存確認を経てモデル・解析条件を復元し、その後に明示的に解析します。通常のモデルJSONには解析条件を加えません。結果はページ再読み込みで消えます。

解析はWorkerで行い、時間応答・Bode・掃引・結果ファイルの確認とは同時に開始しません。正常な解析自体は既存のモデル・時間応答・Bode・編集履歴を保持します。フォーム変更・中止後のCSVは実行済み結果を保持し、モデル編集／Undoは結果を無効にします。古い返答や遅延したファイル読み込みは新しい解析へ反映しません。

CSVには全極・零点、定数／零多項式／未解決の区別、解析対象・方式・係数・Routh判定・右半平面個数・残差・警告を残します。保存した方式の記録を、現在のフォーム値で過去の結果へ付け替えません。

## 数値検証とサンプル

[feedback-plan.json](../samples/pole-zero/feedback-plan.json) を「極・零点設定を読み込む」で復元します。対象はL(s)=K/[s(s+1)(s+2)]、方式は仮定した単位負帰還。分母はs³+3s²+2s+Kです。

| K | 判定 | 右半平面の極 | 代表的な極 |
|---:|---|---:|---|
| 4 | 漸近安定 | 0 | −2.796321903、−0.101839048±j1.191670796 |
| 6 | 境界 | 0 | −3、±j√2 |
| 8 | 不安定 | 2 | −3.166312747、0.083156374±j1.587350998 |

`cargo run --locked -p blocksim-core --example pole_zero` では独立したCardano式と照合し、3ケースの最大座標誤差は2.42e−15未満でした。さらに、**別のモデルとしてT=N/(D+N)を明示的に作り**、RK45の単位Step応答を100秒・2001点で計算しました。80〜100秒の範囲はK4で0.999769923〜1.000222390、K6で0.095487920〜1.904529162、K8は最大絶対値約3359.13となり、減衰・持続振動・増大を確認しました。選択した元モデルを暗黙に閉ループへ書き換えたものではありません。

詳細は [pole-zero-validation.json](pole-zero-validation.json)。このサンプルの誤差や時間応答から、任意のモデルやブロック図全体の安定性・精度を保証しません。モデル全体の固有値解析、Nyquist判定、離散系、非線形の線形化、最小実現は未実装です。

接続された複数ブロックのうち、選択Scope成分の祖先を対象とする最大8状態の解析は [状態空間仕様](state-space.md) を参照してください。ここで選択した伝達関数と仮定した負帰還の判定対象は変わりません。
