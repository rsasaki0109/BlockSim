# StateSpace行列の離散化

連続モードのStateSpaceを選択すると、「行列の連続 → 離散」でZOH／Tustin、サンプル周期、Tustinの任意のプリワープ周波数を設定できます。「変換行列を確認」は適用済みの行列からAd・Bd・Cd・Dd、初期状態と残差を計算するだけです。上のブロック設定を編集した場合は先に適用してください。

確認時に離散モデルの時計・寸法・代数ループも検証します。「離散行列へ変換」は選択ブロックのparamsだけを通常の履歴1回で置き換えます。ID、幅、位置、接続、他のブロック、記録刻み、ソルバ、解析の領域選択を保持し、Undo／Redo・モデルJSON・ブラウザ保存／復元を使えます。方式／周期／プリワープやモデルの変更で確認は無効になります。実行・解析・掃引・ファイル検証中の変換は拒否します。

状態0〜16、入力・出力各1〜8、矩形のB・C・Dに対応。サンプル周期は正の有限値で、適用先ではroot dtの整数倍1〜100000が必要です。非可観測・不安定な状態も残し、最小実現／極零相殺はしません。ブロックのモード選択は、今までどおり行列を同じ値のまま解釈する操作です。ここでの確認・変換とは別です。

## ZOH

```text
exp(Ts * [[A, B], [0, 0]]) = [[Ad, Bd], [0, I]]
Cd=C, Dd=D, initial_d=initial_c
```

元の状態座標と非ゼロ初期状態を保ちます。Aの逆行列は不要で、積分器や重複極にも対応。入力が各区間で一定に保持される条件で、連続系のサンプル時刻の応答に一致します。サンプル間の離散出力は保持されるので、その間の連続応答に一致する意味ではありません。サンプルの途中に変わるStepや保持しないSine、連続帰還モデル全体の一致も保証しません。

既存ZOHの行列指数を共有し、拡張行列の最大寸法は24。∞ノルムを0.5以下へ縮小し、最大24回の二乗／32項のTaylor、項ノルム ≤ 2e−17×max(1,結果ノルム)で終了します。A Bd=(Ad−I)Bの残差を `max|lhs−rhs|/(1+||A||||Bd||+||Ad−I||||B||)` で計算し、1e−10超は未解決として拒否します。プリワープは受け付けません。

## Tustin

h=1/k、M=I−hAとして、次の実現を使います。

```text
k=2/Ts、または omega_p / tan(omega_p Ts/2)
Ad=2 M^-1−I
Bd=2h M^-1 B
Cd=C M^-1
Dd=D+h C M^-1 B
```

`s=k(z−1)/(z+1)` の周波数写像に対応します。プリワープは `0<omega_p<π/Ts`、指定した周波数を合わせる操作です。ZOHと同じ時間応答を作る意味ではありません。元の連続初期状態と変換後の座標の対応には初回入力も関わるため、今回は**初期状態0のみ**。非ゼロはリセットせず、確認を拒否して元設定を残します。変換後のt=0の出力はDd u[0]であり、元のD u[0]と異なる場合があります。

∞ノルムで尺度調整した部分ピボット付きGauss–Jordanを使い、ピボット絶対値1e−12未満・逆行列確認 `max|M M^-1−I|>1e−10` は拒否。直接項が新たに現れて接続が代数ループになる場合も拒否します。Delayを自動追加したり、接続を変更したりしません。

両方式とも、非有限係数／結果、検出した乗算／尺度調整のアンダーフロー、演算・予算・収束の未解決を拒否します。残差は必要な検査であって、任意の行列の全体誤差や安定性の証明ではありません。

## サンプルと再利用

GUIサンプル「行列のZOH／Tustin離散化」は[モデルJSON](../samples/matrix/discretization.json)から読み込めます。A=[[-1,0],[1,−2]]、B=[[1,1],[0,2]]、C=I、D=diag(0.25,0.5)、初期状態0。u=[1,2]を1.2秒に[0.25,−1]へ変更。Ts=0.1秒で方式を比較できます。非ゼロ初期値[0.5,−0.25]のZOHも独立区間式で確認します。

モデルには変換後の行列・初期状態・離散モード・周期を保存します。方式／プリワープ／元連続行列の来歴は追加しません。再変換する場合は元の連続モデルも別ファイルへ保存してください。全モデルの一括離散化、一般の非ゼロTustin状態写像、混在周期のlifting、伝達関数の次数上限拡張は含みません。

Rust: `graph::discretize::{MatrixRequest,MatrixResult,MatrixMethod,discretize_matrix}`。WASM: `discretize_matrix(request_json)`、1 MBの厳密JSON境界。行列／initial／sample_time／methodは必須、未知項目・不足・不正寸法を拒否します。previewのrequestには実行した元行列と条件を含め、GUI適用時にも対象の一致を再確認します。

数値・実行したテスト・途中の不具合は[検証記録](validation.md)、実行と保持の規則は[StateSpaceブロック](matrix-block.md)を参照してください。


GUIで[行列の保持入力応答比較](matrix-comparison.md)を使うと、選択した行列を単独で実行し、同じベクトル入力の連続／離散の全出力差分、条件保存／復元を確認できます。元モデルへの変換適用とは別操作です。
