# 任意ベクトル入力での行列応答比較

連続StateSpaceの設定欄から「行列の保持入力応答比較」を開き、「比較入力」を「任意のベクトル入力系列」へ切り替えます。JSONは行=サンプル、列=入力成分。1〜2001行、入力数m（Dの列数、1〜8）と同じ列数の有限値を指定します。比較点数は初回を含む2〜2001で、表の行数とは別に指定できます。

各行を変換周期Tsの間保持します。繰り返しなしでは表の終わり以降も最終行を保持し、繰り返しありでは整数のサンプル番号kで `values[k % rows]` を使います。1行はどちらでも一定入力。表より少ない比較点数も、途中で終わる周期も指定できます。入力が先頭行へ戻っても連続・離散のプラント状態を初期値へ戻しません。

元モデルの接続・入力・時計・ソルバ・完了結果は保持し、選択した行列だけの連続RK45と変換後離散モデルへ同じSampled Inputを与えます。両方の実入力を全記録点で比較し、指定した行と保持にも一致することを確認してから、Tsごとの全出力を取り出します。記録刻みTs/10、許容誤差・計算予算・行列と初期値の規則は[行列比較仕様](matrix-comparison.md)と同じです。ZOHは非ゼロ初期状態を保ち、Tustinは初期状態0のみ。

系列では全区間の各出力の最大差・RMSを表示します。「入力変更後」という単一の区間は定義しないため、その指標とchange_timeを結果へ追加しません。出力を切り替えると、実線の離散／破線の連続をサンプル点で比較できます。サンプル間の出力を再構成した表示ではありません。

## CSVと保存形式

入力CSVは100 KBまで、1行1サンプル、数値のみ。見出しは1列なら `input`、複数列なら `input_0,input_1,...`。見出しなし、BOM、CRLF、科学表記にも対応します。空行・引用符・時刻列・異なる列数は拒否します。CSVは入力行だけを読み書きし、周期・繰り返し・比較点数は現在の条件を保持します。読み込み／編集だけでは比較を実行せず、前回結果や元モデルを変更しません。

比較設定は引き続き `blocksim.matrix-comparison` version1です。入力系列を使う場合はinputを次の形で保存します。

```json
{"kind":"sample_sequence","values":[[1,2],[0.25,-1],[-2,0.5],[0,0]],"repeat":true}
```

repeatは任意のboolean、省略／falseは最終行保持です。正規化して保存する際はfalseを省略します。元行列・初期値・方式・Ts・プリワープ、点数も保存。読み戻しは同じ選択行列・初期値へ条件だけを復元し、再実行します。旧version1のinput={before,after,change_sample}と、旧比較結果・CSVの項目は維持しています。系列にはstepの項目を混ぜません。

比較設定全体も100 KB上限です。入力CSVの100 KB内でも、行列やJSONの構造を含めて上限を超える場合は比較／条件保存を拒否します。元モデルや完了結果は保持します。

比較結果JSONは実行した入力行・repeat・点数と全実入力・連続／離散出力・指標を含みます。結果CSVは従来の共通項目にsample_index、cycle_index、row_index、input_rows、repeatを追加。繰り返しなしのcycle_indexは0、最終行保持時のrow_indexは最終行です。change_sample列は空欄です。全点×全出力を出力し、条件や表示成分の編集で前回の結果を新条件へ付け替えません。

遅延CSV読み込みは入力・repeat・点数・方式／周期・モデル／選択、他の実行の開始／完了で破棄します。比較計算・通常実行・解析・掃引・ファイル検証・変換との排他と中止、前回結果保持は従来どおりです。不正ファイル／セル／寸法／行数は適用せず、直前の入力表と完了結果を保持します。

## サンプルと範囲

[4行2成分CSV](../samples/matrix/vector-sequence.csv)と[比較設定JSON](../samples/matrix/sequence-comparison-plan.json)を追加しました。モデルサンプル「行列のZOH／Tustin離散化」の初期状態を[0.5,−0.25]へ適用し、比較設定を読み込めます。A=[[-1,0],[1,−2]]、B=[[1,1],[0,2]]、C=I、D=diag(0.25,0.5)、ZOH／Ts=0.1、13点で4行を繰り返し、3周期＋次の先頭行まで比較します。繰り返しを外して同じ13点を実行すると、4行目以降は[0,0]を保持します。

独立した各保持区間の指数式、Tustinの行列漸化式、実入力、状態継続、0状態の矩形、最大2001行・8入出力、CSV／条件保存復元・遅延読み込み・320pxを検証します。[検証記録](validation.md)に数値と実施結果を残します。非均一時刻、補間、元モデル全体の比較、一般の非ゼロTustin状態写像、混在周期のliftingや一般的な誤差・安定性証明は対象外です。
