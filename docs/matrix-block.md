# StateSpaceブロック

ブロック図のパレットからStateSpaceを追加し、設定欄のA・B・C・Dと初期状態をJSON配列で編集できます。連続／離散モードを選び、離散系ではサンプル周期を設定します。モデルサンプルにも連続・離散の2入力2出力モデルを追加しています。

| 行列・設定 | 形状・意味 |
|---|---|
| A | n×n、状態間の結合 |
| B | n×m、入力から状態への作用 |
| C | p×n、状態から出力への作用 |
| D | p×m、入力から出力への直接項 |
| initial | n個の内部状態。過去の出力列ではありません |
| 信号幅 | 出力数p。入力ポートの幅mはDの列数から決まります |
| mode | continuousまたはdiscrete |
| sample_time | 正の有限値。離散系は記録刻みdtの整数倍1〜100000 |

状態n=0〜16、入力m・出力p=1〜8。係数と初期状態はすべて有限値、行の長さ・形状は厳密に一致させます。未知項目・不足・nullを拒否します。n=0ではA=[]、B=[]、Cはp行の空配列、initial=[]で、Dだけの静的なモデルになります。初期状態・周期・モード・行列をすべて保存します。

## 連続・離散の演算

連続系は `ẋ=Ax+Bu, y=Cx+Du`。結合した全状態を既存のRK4／RK45の同じステージで更新し、初期状態と他のブロックの状態も一緒に扱います。連続モードではsample_timeを計算に使いませんが、正の値を保持します。任意の行列・刻みで安定や精度を保証する機能ではありません。

離散系は `x[k+1]=Ax[k]+Bu[k], y[k]=Cx[k]+Du[k]`。t=0では指定したx[0]と現在のu[0]からy[0]を計算し、x[1]を取得します。最初の状態更新はTsです。全行の次状態を同じx[k]・u[k]から同期して取得し、順番に更新した新しい状態を他の行へ混ぜません。yとDの直接項を含めて、サンプル間は保持します。間で入力が変わっても、次のサンプル時刻まで出力を更新しません。RKステージやRK45の棄却で離散状態を進めません。

モードを切り替えると、同じ行列を選んだ領域の式として使います。連続Aをexp(A Ts)へ変換する操作ではありません。連続と離散の行列を用意し、必要な領域の値を設定してください。

## 内部実装と解析への接続

保存したStateSpaceブロックを、実行時だけ既存のIntegrator／Delay・成分Selector・重み付きSum・Muxへ展開します。離散出力は0次のDiscrete TransferFunctionで現在サンプルの値を保持します。保存モデルやUndo／Redoの履歴を展開済みブロックへ置き換えません。

各出力のC行には0係数の状態も含め、出力に見えない内部状態を解析時に削除しません。Dの0係数は直接依存を作らず、D全体が0なら状態で負帰還の循環を切れます。直接項がある代数ループは従来どおり拒否します。ベクトルの一部成分だけで解ける循環を、一般の代数方程式として解く機能はありません。

連続・同一周期離散の状態空間／MIMO／周波数応答には、同じ実行式から接続できます。他の関連ブロックを含めた状態空間解析は最大16状態・関連128変数です。初期条件は時間応答に使いますが、線形の行列・周波数応答の単位入力解析ではゼロにします。非可観測・不安定な状態、固有値の未解決・数値ランクの未確定を保持し、最小実現へ自動変換しません。[MIMO仕様](mimo.md)と[状態空間仕様](state-space.md)を参照してください。

状態一覧では `matrix/state-0` のようなIDの0からn−1が、指定したinitialの添字に対応します。診断の内部IDはGUIで元のStateSpaceブロックと入力ポートへ案内します。内部実装の階層は、ユーザーのサブシステム8階層の予算に加算しません。

既存の展開後256ブロック・4096接続・計算量／記録量の予算を維持します。密な16状態・8入力・8出力の1ブロックは既存の予算内へ展開できますが、多数の行列ブロックを追加すれば上限に達します。有限な係数でも演算が非有限になればエラーとして停止し、0や制限値で埋めません。

## 編集・保存と互換性

入力幅と出力幅が違うポートでも、接続時にそれぞれの幅を確認します。行列・モード・周期・初期状態の編集は通常のモデル履歴を使い、無効な適用／読み込みは元モデルと完了結果を保持します。コピー／貼り付け、サブシステム、モデルJSON・ブラウザ保存／復元に対応。実行のたびにinitialから始まり、実行終了時の状態から自動再開しません。

新しいkindは `state_space`、GraphModel.version1とGraphDocument.version2を維持します。a／b／c／d／initial／mode／sample_timeは必須です。既存ブロックやPIDの既定値・モデル項目・結果の演算は変えません。係数各要素・初期状態各要素・周期は掃引候補にも含みます。

## 独立式で確認するサンプル

[連続2入力2出力](../samples/matrix/continuous-plan.json)はA=[[-1,0],[1,−2]]、B=[[1,1],[0,2]]、C=I、D=diag(0.25,0.5)、initial=[0.5,−0.25]。u=[1,2]を1.23秒で[0.25,−1]へ変更します。各一定入力区間でa=u0+u1、b=2u1、区間始めの状態を(x0,x1)とすると、

```text
x0(t) = a + (x0−a) exp(−t)
x1(t) = x1 exp(−2t) + (a+b)/2 · (1−exp(−2t))
        + (x0−a) · (exp(−t)−exp(−2t))
y(t)  = [x0(t)+0.25u0, x1(t)+0.5u1]
```

変更前の式で変更時の状態を求め、それを変更後の初期値にして比較します。

[離散サンプル](../samples/matrix/discrete-plan.json)はA=[[0.8,0],[0.1,0.7]]、B=[[0.2,0.1],[0,0.3]]、同じC・D・初期状態、Ts=0.1秒です。uは0.15秒に変更。0.1秒の取得値は0.2秒の状態更新に使い、0.2秒の出力直接項にはその時点の新しい入力を使います。0.15秒の入力変更時には出力を保持します。

両モデルの全時間点、独立した逆行列の全4経路、0状態の2入力3出力、初期応答だけの系、非可観測な不安定モード、D=0の負帰還、密な16状態と8階層、保存復元・無効な形状・演算オーバーフローを検証します。結果と途中の失敗は[検証記録](validation.md)に記載します。
