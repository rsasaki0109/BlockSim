# 行列比較の作業状態を保存する

比較が完了したら「作業状態 JSON」で、実行済みの全結果と現在のカーソル位置・表示出力・評価区間を一緒に保存できます。「比較結果／作業状態を読み込む」から開くと、現在のWASMで全結果を再計算し、一致した後に同じ点と区間を表示します。評価区間の欄は復元時に開きます。

元モデルはファイルへ含めません。別セッションでは元のモデルを開き、同じ連続StateSpaceを選んでください。成功時に実行時の方式・周期・プリワープ・入力・点数も戻します。元モデル・履歴・完了Scope結果を変更せず、離散化を自動適用しません。

未実行の編集中の条件は保存しません。保存対象は前回実行した条件と全取得値、その結果を閲覧する位置です。条件を編集していても、保存／復元する結果の意味は変わりません。

## ファイルと互換性

形式は `blocksim.matrix-comparison-session`／version1です。

- `report` は既存の `blocksim.matrix-comparison-result`／version1の全結果です。
- `view.sample` はカーソルの元サンプル番号、`view.component` は表示出力の元成分番号。
- `view.start_sample`／`view.end_sample` は両端を含む評価区間です。

番号はすべて0からの整数で、保存した結果の点数・出力数の範囲内が必要です。開始≦終了、1点だけの区間も有効です。カーソルが評価区間の外にある状態も保存できます。表示点や区間を補間・丸めたり、番号を振り直したりしません。

旧「比較結果 JSON」の形式と内容は維持します。旧結果ファイルを読み込んだ場合は、従来どおりカーソル0・出力0・全区間になります。比較条件JSONと区間結果JSONは作業状態ファイルとは別です。

上限はラッパーと表示状態を含むファイル全体で8 MiB、内側の比較条件は100 KB。全結果の点数・信号幅・取得時計・実入力・指標・変換データの検査と、現在のWASMの全取得値／全項目への厳密一致は[結果の読み戻し](matrix-result-file.md)と同じです。表示状態にも未知項目・空欄・小数・範囲外・逆転した両端を認めません。

## 無効な状態と読み込み中の操作

画面でカーソル番号や区間を不正に入力した場合、前回の有効な表示を保持し、作業状態の保存を無効にします。有効な番号へ修正してから保存してください。全結果JSON／CSVの保存は従来どおり可能です。

不正な作業状態や再計算との不一致、中止は、前回結果・カーソル・区間・現在の設定を保持します。成功するまで設定や表示を部分的に復元しません。検証の実行中は作業状態の保存を待ちます。

遅延したファイル読み取り中のカーソル／成分／区間の閲覧だけでは、読み込みを破棄しません。成功時はファイル内の表示状態へ戻ります。条件・モデル・選択の変更や別実行・新しい読み込みで古いファイルを破棄する規則は既存の読み戻しと同じです。

モデル全体の作業環境、編集履歴、未実行の条件、レイアウト、パネルの開閉状態一般、別実装／OS／バージョンをまたぐ結果保証を保存する機能ではありません。[検証記録](validation.md)に実際のチェックと制限を記載します。

[最大差への移動](matrix-peak.md)で、指定区間の全出力または出力ごとの最大差がある取得点を確認できます。

[許容差による区間判定](matrix-tolerance.md)では絶対・相対基準と超過点を確認できます。許容差設定は作業状態とは別のJSONで保存します。
